# Browser Copilot

[English](README.md) · **简体中文**

一个真正会**替你操作网页**的 AI 助手。打开侧边栏，用大白话说出需求，Browser Copilot
就会读取你正在看的页面并动手操作——点按钮、填表单、滚动、切换标签，一路走完下单、注册、
配置等整段流程；你可以在旁边盯着逐步确认，也可以放手让它自动完成。

- 🧠 **用你已经在用的模型。** 任意 OpenAI 兼容端点：DeepSeek、火山方舟、OpenAI、
  OpenRouter、Moonshot、百炼、硅基流动，或本地 Ollama/LM Studio，自带密钥即可。
- 🎚️ **自主程度由你决定。** 四种模式，从纯聊天到全自动；半自动下每次点击都先给你确认。
- 🧩 **技能（Skills）** 把可复用的经验（评审清单、文案风格、提取格式）存成一键指令，
  模型必须严格遵循。
- 🎬 **工作流让整套流程自动跑。** 录制一遍操作，或在可视化画布上用 56 种块搭出流程——点击、
  填写、循环、条件分支，甚至 AI agent 步骤——然后手动运行、定时运行、浏览器启动时运行、
  按快捷键触发、从右键菜单触发，或打开匹配页面时自动运行。
- ⏰ **能定时干活，睡觉时也不闲着。** 设置每隔几分钟、每天或工作日自动运行的任务——
  无人值守执行一条指令，或汇总你的 GitHub 待评审 PR，并保留完整运行记录。
- 💬 **从飞书派活、收结果。** 任务完成自动推送到群聊；也可以在手机上私聊机器人下达指令，
  它会在你电脑的浏览器里执行并把结果回复给你。
- 🤝 **编码助手也能驱动它。** Claude Code、Codex、Trae——任何 MCP 客户端——都能通过
  本地适配器获得一套浏览器工具，直接操作你真实的 Chrome（见
  [Agent 接入](#agent-接入mcp)）。
- 🔒 **天生注重隐私。** 无需账号、无埋点、无云服务器；密钥和数据只保存在你的电脑上，
  密码本地填写、绝不会展示给模型。
- 💾 **数据就是你硬盘上的文件。** 在设置里选一个文件夹，对话、技能、工作流都会以真实文件
  落盘，浏览器缓存只作为镜像备份。

它不会自作主张地行动——每个动作要么是在执行你刚提出的请求，要么来自你创建的
[定时任务](#定时任务)，要么来自你搭建并启用了触发器的[工作流](#工作流)，要么是你从
[飞书](#飞书接入)发来的指令，要么是你在[本地接入](#agent-接入mcp)的编码 agent 通过
MCP 发来的工具调用。

## 快速开始

### 1. 安装扩展

需要 **Chrome 116+**（或任何支持 Manifest V3 侧边栏的 Chromium 浏览器）。

**方式一：下载发行版（推荐）**

1. 前往
   [**Releases**](https://github.com/dcc123456/browser-copilot/releases) 页面，
   下载最新版本里的 `browser-copilot-<版本>.zip`。
2. 解压到一个会**长期保留**的文件夹——扩展会从该文件夹加载，之后不要删除它。
3. 打开 `chrome://extensions`。
4. 打开右上角的**开发者模式**开关。
5. 点击**加载已解压的扩展程序**，选择解压出来的文件夹——即直接包含
   `manifest.json` 的那一层。
6. 点击工具栏上的扩展图标打开侧边栏；建议把它固定到工具栏方便使用。

**方式二：从源码构建**

需要 **Node.js 20+** 和 `pnpm`（或 `npm`）。

```bash
git clone git@github.com:dcc123456/browser-copilot.git
cd browser-copilot
pnpm install
pnpm run build
```

然后在 `chrome://extensions`（开启开发者模式）点击**加载已解压的扩展程序**，
选择构建出来的 **`dist/`** 目录。以后拉取新代码后，重新执行 `pnpm run build`，
并在扩展卡片上点**重新加载**——仅重新构建不会刷新已加载的 service worker。

### 2. 添加模型

打开侧边栏 → **设置 → 添加模型服务**。

1. **选一个预设**——接口地址和建议模型会自动填好（DeepSeek、火山方舟、OpenAI、
   OpenRouter、Moonshot、百炼、硅基流动、Ollama 等）；也可选**自定义**接入任意
   OpenAI 兼容端点。
2. **粘贴 API 密钥**。本地 Ollama/LM Studio 填任意非空字符串即可。
3. **填模型**——手动输入模型 ID，或点**获取模型列表**让端点返回可用模型
   （即使网关没有 `/models`，手动输入也始终有效）。
4. 点**测试连接**——它会发一次真实请求，同时验证密钥和模型是否都可用。
5. **保存**。可以添加任意多个服务，用**使用这个**在它们之间切换。

> 模型必须支持 **function calling（工具调用）**。不支持的话，助手只能聊天，无法
> 主动读取或操作页面。日常可靠选择有 `deepseek-chat`、`gpt-4o-mini`、`qwen-plus`；
> 难任务用推理模型，隐私敏感用本地模型。

### 3. 选择自主程度

用聊天框左下角的下拉框选择。选择作用于**下一个动作**，即使回答进行中也能切换：

- 💬 **聊天**——纯对话，不读取也不操作页面（最省 token）。
- 🔒 **只读**——只能读取，不点击、不输入、不跳转、不填写。
- 🛡 **半自动**（默认）——每个改变页面的动作都先展示给你确认。
- ⚡ **全自动**——动作不再确认直接执行。

### 4. 开始提问

输入后按 **Enter** 发送（Shift+Enter 换行；使用中文/日文/韩文输入法时，第一次
回车确认候选词、第二次才发送）。

- 勾选**附带选中内容**，发送你在页面上高亮的文字（只发选区，不发整页）。
- 在输入框打 **`/`** 可选择[技能](#技能skills)。
- 选中技能后甚至可以发空消息——它会把技能应用到你的输入或选中内容上。

回复以 Markdown 渲染。可以随时关闭面板，回答会在后台继续，重新打开时自动恢复。

## 能用来做什么

最适合"任务发生在一个页面上、又需要读和操作结合"的场景：

- **填写表单**：套用已保存的资料；密码会直接填进字段，模型自始至终看不到密码值。
- **走完多步流程**：加购物车、结账、改设置——半自动逐步确认，全自动一路执行。
- **评审 PR、看懂代码/文档**：先选中关心的那段，给模型一个精确目标而不是整页。
- **总结**长文章、文档、release notes、长帖。
- **分析页面数据**：但模型是在对*文本*推理而不是计算，长表格里的数字请当作待验证的假设。
- 配合[技能](#技能skills)套用可复用的标准（评审规范、文案风格、检查清单）。

它做不到：在聊天或只读模式下操作页面；读取 `chrome://`、本地文件或应用商店页面；解验证码或绕过
二次验证；保证长表格算术正确；在浏览器完全关闭时运行任务（定时任务只在浏览器开着时触发）。

## 代理模式

下拉框的选择作用于**下一个动作**，即使回答正在进行中也能立即切换。

| 模式 | 行为 | 适用场景 |
| --- | --- | --- |
| 💬 **聊天** | 纯对话。不向模型发送读页面或操作工具，因此不会碰页面，token 消耗最低。仍可附带选中的文字。 | 头脑风暴、写作、问答、翻译——不希望它操作页面时。 |
| 🔒 **只读** | 只能读取，不点击/输入/跳转/填写。 | 评审、总结、翻译——零副作用。 |
| 🛡 **半自动**（默认） | 每个改变页面的动作都先给你确认。 | 日常使用；每一步都可控。 |
| ⚡ **全自动** | 动作不再确认直接执行。 | 你信任的、重复性流程。 |

半自动下确认卡片会准确显示要点哪个按钮、填哪个字段、打开哪个 URL。全自动下每个动作仍记录在
**数据**标签的操作历史里，事后可审计。

## 模型

任何遵循 OpenAI chat-completions 协议的端点
（`POST {baseUrl}/chat/completions`、`Bearer` 认证、SSE 流式返回）。provider 只是配置，
不是代码分支，没列出的端点同样能用。

| 预设 | 接口地址 | 模型示例 |
| --- | --- | --- |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat`、`deepseek-reasoner` |
| 火山方舟 Ark | `https://ark.cn-beijing.volces.com/api/v3` | `doubao-seed-code`，或 `ep-…` |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| OpenRouter | `https://openrouter.ai/api/v1` | `deepseek/deepseek-chat` |
| Moonshot / Kimi | `https://api.moonshot.cn/v1` | `kimi-k2-0905-preview` |
| 阿里云百炼 DashScope | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| 硅基流动 SiliconFlow | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V3` |
| Ollama（本地） | `http://localhost:11434/v1` | `qwen3:8b` |
| LM Studio（本地） | `http://localhost:1234/v1` | `local-model` |

**怎么选**：要让它自主读页面/动手，必须选支持工具调用的模型。日常用便宜快的
（`deepseek-chat`、`gpt-4o-mini`、`qwen-plus`），难任务用推理模型，敏感内容用本地模型。
页面文本上限约 12,000 字符，长页面优先选大上下文模型。

可添加多个服务，用**使用这个**切换；密钥按配置分别保存。**每条回复最多操作步数**（默认 20，
范围 1–100）用于限制模型陷入循环，碰到上限发"继续"即可。密钥保存在本机（选定存储文件夹后
即为磁盘文件；不同步、不加密），不能接受请改用本地模型。

## 使用说明

- **窗口作用域**：所有由面板发起的操作（读取/操作页面、新开/切换/关闭标签、从面板运行
  工作流）只作用于**打开面板的那个浏览器窗口**；定时任务、飞书指令等无人值守任务在面板
  开着时也同样锁定该窗口。你可以再开一个没有面板的窗口自己随意使用——它不会被读取、
  不会被操作，也不会触发"打开匹配页面时自动运行"的工作流触发器。只有在任何窗口都没有
  打开面板时，无人值守任务才按原有全局逻辑运行；键盘快捷键和右键菜单在工作流发生的
  那个窗口生效。
- **读取页面**：要么勾选**附带选中内容**直接发送高亮文字，要么让助手自己读取（半自动下未附带
  时会先确认）。免确认仅限那个页面（按 origin + 路径比对），切到别的标签会重新询问。
- **附带选中内容**只采集 `window.getSelection()`，发什么由你精确控制。
- **Markdown**：回复渲染标题、列表、表格、带复制按钮的代码块；你自己输入的内容保持原样。
- **语言与主题**：设置 → 语言（English / 简体中文 / 自动）；面板跟随系统浅色/深色主题实时切换。
- **存储位置**：设置 → 存储位置 可选一个磁盘文件夹，之后所有数据都会以真实文件写入该目录
  （详见[保存的数据与隐私](#保存的数据与隐私)）；未选择前数据保存在浏览器存储里。
- **历史**：时钟图标打开历史对话，可继续、预览、重命名、删除。会话保存在本机
  （每条保留最新 200 条消息）——选定存储文件夹后即为磁盘上的真实文件。

## 技能（Skills）

技能是一段存下来的指令包，把提示词里不变的部分固定下来。在**技能 → 新建技能**里填名称、
一句话适用场景和具体指令。然后二选一：在输入框打 **`/`** 手动选择，或保持"允许 agent 自动
应用"开启，让它在消息匹配时自行使用。

技能一旦被选中，会被**强制应用到该轮**：完整指令注入系统提示词，用户消息也被绑定为按该技能
处理，模型无法绕过技能作答。前期只提供名称和说明，完整指令按需加载。

**技能像通用技能一样以文件保存。** 每个技能对应一个以其 slug 命名的文件夹，内含一份
`SKILL.md`：YAML frontmatter（`name`、`description`、`autoMatch` 等）+ Markdown 正文指令。
选定存储文件夹后，它们位于磁盘上的 `skills/<slug>/SKILL.md`，你可以直接手改，Browser Copilot
会读取最新内容；未选文件夹时回退到浏览器存储。

## 工作流

**工作流**标签把一套可重复的浏览器操作变成保存下来、可反复运行的自动化——在可视化画布上
搭建的节点图，设计上对齐 [Automa](https://github.com/AutomaApp/automa)。在该标签创建工作流，
点**编辑**会在独立标签页打开完整的流程编辑器。

**三种创建方式：**

- **录制**：在编辑器里点录制，把任务做一遍。点击、表单输入（文本/下拉/复选/单选）、滚动、
  切换标签、新开标签、整页跳转和 SPA 路由变化都会被捕获成块——包括等待元素出现/等待页面
  加载的停顿。停止录制后，流程自动变成画布上的工作流。
- **聊天转换**：一轮聊天里实际操作过页面后，可以把已执行的动作保存为工作流，之后不再经过
  模型也能复用。
- **手动搭建**：从块面板拖出节点、连线即可。

**块里有什么。** 从 Automa 移植的 56 种可执行块：点击/悬停/滚动元素、填表、读文本、判断元素
存在、按数据或元素循环、while/重复执行、条件分支、变量与 `{{token}}` 插值、JavaScript 代码、
Cookie、Webhook、剪贴板、截图、下载处理、新建/切换/刷新/关闭标签、延时等。（Automa 的
5 个*云*块——Google 表格/云盘、块包、云端 AI 工作流——仅为兼容而列出，不可执行。）每种块
都有专属编辑表单，可以单独停用，也能配置自己的错误处理：失败时重试或改走另一条分支。

**精确定位目标。** 内置元素选择器可为任意目标生成 CSS 或 XPath 选择器——悬停高亮、点击锁定、
在 DOM 里上下行走、CSS/XPath 一键切换。位于*闭合* shadow DOM 内部的目标可通过 Chrome
DevTools Protocol 点击。画布支持一键自动布局；`Ctrl+S` 保存，`Ctrl+Enter` 运行。

**一个特殊块：AI agent。** 它把这一步交给与聊天相同的 agent 循环——只读模式下它读取页面
（或指定元素）并回答、不做任何操作；全自动模式下它可以点击和跳转。回答会存进输出变量，
供后面的块插值使用。

**触发方式。** 工作流在触发器生效时运行：

- **手动**——编辑器或工作流标签里的运行按钮；
- **定时**——与[定时任务](#定时任务)相同的排程选项（每隔 N 分钟、每天或所选星期）；
- **浏览器启动时**、**键盘快捷键**（每个工作流可自定义，如 `Ctrl+Shift+E`）、**右键菜单**、
  或**打开 URL 匹配指定模式的页面时**。

**查看运行。** 历史标签的活动板统一展示工作流与任务的运行中和已完成记录——实时进度、按块
日志、调试模式、中途取消。工作流标签显示每个工作流的上次运行状态，失败的运行可一键直达
其日志。

**导入导出。** 支持导出单个或全部工作流为 JSON，并可导入 JSON——包括从 Automa 导出的文件。
旧版工作流格式在加载时自动迁移。

## 定时任务

**任务**标签可以让助手在你设定的时间**无人值守地运行**——不用开着面板、不用点按钮。创建一个
任务，选择做什么、什么时候做，浏览器开着时它就会自动执行。

**能做什么：**

- **运行一条助手指令（agent prompt）**——把一段指令存下来，助手会像你在聊天里发送一样执行它，
  包括按当前模式读取或操作页面。适合做定期检查、每日摘要、自动填写并提交等流程。
- **统计 GitHub 上待你评审的 PR 数量**——内置任务。

**什么时候运行**（使用 Chrome 的 `chrome.alarms`，最短 1 分钟）：

- 每隔 N 分钟；
- 每天固定时间；
- 工作日（周一至周五）固定时间。

每次运行都会记录在**最近运行**里：开始时间、结果、执行步骤和摘要，也可以中途终止。任务只在
**浏览器开着时**触发（由 alarm 唤醒 service worker），Chrome 关闭时不运行。打开"完成时通过飞书
通知"即可把结果推送到飞书。

## 飞书接入

Browser Copilot 能以两种相互独立的方式接入[飞书](https://www.feishu.cn)，都在**任务**标签配置：

- **主动通知（自定义机器人 webhook）。** 填入飞书群自定义机器人的 webhook 地址（以及可选的
  签名校验密钥），任何任务完成后都可以把结果发到那个群。不需要应用凭据，是"完成后告诉我一声"
  最简单的方式。
- **接收指令远程控制（自建应用 + 长连接）。** 填入飞书自建应用的 App ID 和 App Secret 并开启
  机器人，你就可以在飞书上给机器人发消息，它会把你的消息当作一条助手任务在你这台机器上执行，
  并把结果回复给你——相当于从手机或另一台设备远程驱动浏览器。

飞书连接由一个看门狗 alarm 保活，断线会自动重连。没有填应用凭据时，通知仍可用，但无法接收
指令。

## Agent 接入（MCP）

侧边栏不是唯一的入口。开启**本地 Agent 接入**后，Browser Copilot 会通过
[MCP](https://modelcontextprotocol.io) 向同一台机器上的编码 agent 暴露一组浏览器
工具——Claude Code、Codex、Trae 或任何 MCP 客户端都行。agent 由此可以打开网址、读取
页面、点击、填表、按键、切换标签页、执行 JavaScript、识别验证码文字、保存文件——都发生
在你真实的 Chrome 里，"改完代码、回浏览器验证"从此在一段对话里完成。

```
Claude Code / Codex / Trae   （MCP 客户端）
     │  stdio · JSON-RPC 2.0 —— 适配器由 agent 自动拉起
     ▼
examples/local-agent/mcp-server.mjs   （零依赖 Node 适配器）
     │  WebSocket · ws://127.0.0.1:8765   （仅回环）
     ▼
Browser Copilot 插件   （在你的 Chrome 中实际执行每个调用）
```

**环境要求**：Node.js ≥ 18，且 Chrome 已加载本插件。适配器只是仓库里的一个零依赖文件
`examples/local-agent/mcp-server.mjs`——如果你是用发行版 zip 安装的插件，单独下载这一个
文件即可，它不必放在插件目录里。

**手动配置，三步**：

1. 插件侧边栏 → **设置 → 本地 Agent 接入** → 打开开关。适配器地址保持
   `ws://127.0.0.1:8765`，可设置一个共享令牌；链路打通后卡片会显示**已连接**。
2. 注册一条名为 `browser-copilot` 的 stdio MCP 服务，命令为 `node`、参数指向
   `mcp-server.mjs`——设置卡片上就有 Claude Code / Codex / Trae 的现成片段可复制。
3. 启动（或重启）你的 agent——它通过 stdio 自动拉起适配器，插件自动连上。无需常驻
   进程、无需 `npm install`、无需 Python。

## 保存的数据与隐私

**数据**标签保存：可填写的**资料**（姓名/邮箱/电话/地址）、**密码**（通过 `get_secret`
直接填入字段，绝不把值返回给模型）、**操作历史**（每次点击/填写/滚动/跳转，带时间戳和站点）。
所有内容都保存在本机——不同步、不发给模型，密码静态存储时不加密。

**存储位置。** 默认数据保存在 Chrome 的 `chrome.storage.local`。打开**设置 → 存储位置**，
选一个文件夹（通过 File System Access API）即可改为写入磁盘上的真实文件。此后所有数据都会
写进你选定目录下的 `browser-copilot/` 文件夹：

- `conversations/<id>.json` — 对话记录；
- `skills/<slug>/SKILL.md` — [技能](#技能skills)，每个技能一个文件夹；
- `<key>.json` — 其他所有内容：设置、模型服务、工作流、资料、凭据等。

`chrome.storage.local` 降级为只读镜像缓存：磁盘不可用或文件损坏时自动回退读取，写入失败也
不会丢数据。随时可以在同一设置卡片切回浏览器存储；第一次选择文件夹时会把已有数据迁移过去。

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存设置、模型服务、技能、对话、工作流、资料和凭据。 |
| `tabs` | 识别当前标签页，并在你要求时打开/切换/关闭标签（工作流的标签块也需要）。 |
| `scripting` | 注入页面内核、工作流录制器、元素选择器和快捷键监听，以读取或操作标签页。 |
| `sidePanel` | 显示侧边栏。 |
| `alarms` | 唤醒 worker 运行定时任务和工作流，并在开启飞书时为飞书连接保活。 |
| `offscreen` | 运行隐藏文档，让工作流的剪贴板块读写系统剪贴板。 |
| `contextMenus` | 添加右键菜单项，启动配置了右键菜单触发器的工作流。 |
| `webNavigation` | 侦测页面跳转，用于 visit-web 工作流触发器和录制。 |
| `cookies` | 工作流的 Cookie 块读取/设置/删除 Cookie。 |
| `downloads` | 工作流的下载处理块观察和管理下载。 |
| `clipboardRead` | 读取系统剪贴板，供工作流的剪贴板块使用。 |
| `debugger` | 通过 Chrome DevTools Protocol 点击闭合 shadow DOM 内的元素。 |
| `http(s)` 主机权限 | 与页面交互、请求你配置的模型端点，以及开启时请求飞书。 |

没有常驻 content script——在某轮回答、某个定时任务或某个工作流需要之前，不会向任何页面注入
内容。录制工作流、使用元素选择器或启用键盘快捷键触发器期间，会向打开的标签页注入一个只为
该目的服务的小监听器，停止后即移除。alarm 只运行你创建的任务和工作流触发器（以及开启飞书
集成时的保活看门狗）。`debugger` 权限只在工作流需要点击闭合 shadow root 内部时使用。只有
你的消息和你附带/批准的页面文字会离开本机，发往**你自己配置的**端点；任务结果也只有在你
开启时才会发送到飞书。没有埋点、没有统计、本项目不存在任何服务器。

## 开发

```bash
pnpm install
pnpm run dev         # 改动即重新构建
pnpm run typecheck   # tsc --noEmit
pnpm run test        # vitest
pnpm run build       # 生产构建输出到 dist/
pnpm run package     # 构建并生成 releases/browser-copilot-<版本>.zip
```

把 `dist/` 作为已解压扩展加载，改动后在扩展卡片上点**重新加载**。用 npm 也可以。推送 tag 会
运行 `.github/workflows/release.yml`，执行类型检查、测试、构建，并把可加载的 zip 挂到 Release。

关键设计：Markdown 解析成类型化语法树（绝不生成 HTML，没有 `dangerouslySetInnerHTML`）；
页内内核自包含并跨框架注入；选定存储文件夹后，持久化状态写入磁盘真实文件（以
`chrome.storage.local` 作镜像），即使 MV3 service worker 空闲被回收也不丢数据；模式和步数上限
按每个动作读取，改设置无需重新加载。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示未配置模型服务 | 设置 → 添加模型服务。 |
| 401 / 403 | 密钥错误/过期，或密钥与厂商不匹配。 |
| 发送时 404 | 接口地址少了版本段，或模型名不存在；点**测试连接**定位。 |
| 提示无法读取此页面 | `chrome://`、`file://`、应用商店或其他扩展页面，无法注入。 |
| 全自动下仍弹确认 | 重新加载扩展，再确认下拉框显示 ⚡ 全自动。 |
| 提示 "Stopped after N tool rounds" | 达到步数上限，发"继续"或在设置里调高。 |
| 能聊天但从不读页面或动手 | 模型不支持工具调用；手动附带页面或换模型。 |
| 页面文字为空或不全 | 内容在 iframe、懒加载，或在"加载更多"后；先选中关键部分。 |
| 点工具栏图标没反应 | 重新加载扩展，可能是 worker 启动失败。 |

## 已知限制

- 一次聚焦一个标签页；大范围读取看到的是已渲染 DOM（iframe 按动作定位）。
- 面板发起的操作锁定在面板所在窗口内：若该窗口当时只有 `chrome://` 等不可操作页面，
  助手会报"插件窗口内没有可操作的网页标签页"，而不会跨窗口去操作别的窗口。
- 页面文本上限约 12,000 字符，截断会告知模型。
- 工具调用达到配置的步数上限（默认 20）后停止。
- 自主读取和操作需要支持 function calling 的模型。
- 端点必须接受来自浏览器扩展的请求（公开 API 可以，严格的内网网关可能不行）。
- 保存的密码静态存储时不加密。
