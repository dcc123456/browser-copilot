# 快速上手

本页带你熟悉工作流编辑器，并搭建一个完整可运行的工作流：打开页面、读取标题、把文本写入变量，最后保存成文件。

## 打开工作流编辑器

1. 打开 Browser Copilot 侧边栏，选择 **工作流** 标签页。
2. 点击 **新建** 创建工作流，或在已有工作流上点击 **编辑** 打开画布。
3. 编辑器左侧是图，右侧是算子属性面板。**添加算子** 用于展开或收起算子栏；**工作流** 与 **日志** 用于在算子属性、触发器与运行设置、运行历史之间切换。

顶部工具栏有 **保存** 与 **运行**（Ctrl+Enter）。运行时先保存工作流，因此后台执行的图始终就是你看到的那一张。**调试模式** 会为下一次运行启用断点与单步执行。

也可以不手工搭图，直接点击 **录制工作流**：你在页面上的操作会被记录下来，并在结束后作为图打开。

## 认识画布

- 每个工作流都从 **触发器** 算子开始。工作流名称、描述、触发方式与运行设置都在这个算子上。
- 算子栏按分类分组，支持按名称搜索。
- 选中算子后在右侧属性面板中编辑。拖动节点标题可移动节点，**一键美化排版** 可整理整张图。
- 连线从算子的输出（右侧）连到下一个算子的输入（左侧）。分支、回退与循环返回使用额外的命名端口，详见[端口、分支与循环](concepts.zh-CN.md#端口分支与循环)。
- 画布上的改动可以撤销。删除节点或连线不会影响已保存的工作流，直到你再次保存。

## 配置触发器

触发器算子决定工作流何时开始。选中它，用 **添加触发器** 增加一个或多个触发器；第一个是主触发器，工作流卡片上显示的就是它的触发方式。每个触发器都可以单独启用或禁用。

可选的触发方式：

| 触发方式     | 何时触发                                        |
| ------------ | ----------------------------------------------- |
| 手动         | 从编辑器或工作流标签页运行。                    |
| 定时 / Cron  | 间隔若干分钟后再次运行。                        |
| 指定日期     | 到达指定的一次性日期与时间。                    |
| 每周的某几天 | 到达到所选星期与本地时间。                      |
| 访问网页时   | 打开的网址匹配指定模式（glob 或正则表达式）。   |
| 键盘快捷键   | 按下配置的快捷键，可选择仅在输入框之外生效。    |
| 右键菜单     | 从浏览器的右键菜单中选择该工作流。              |
| 浏览器启动时 | 浏览器启动时。                                  |
| 元素变化时   | 页面上匹配 CSS 选择器的元素被插入或发生变化时。 |

需要参数的触发方式会显示对应字段。配置不完整的触发器会被保存，但不会触发；运行前的预检会给出提示。

触发器还可以声明 **输入参数**（名称、类型与默认值）。声明的输入会写入运行的变量表，因此即使调用方没有传值，`{{keyword}}` 也能解析。生成的工作流因此既能直接运行，也仍然可编辑。

## 添加并连接算子

1. 点击 **添加算子**，找到需要的算子。
2. 点击或拖动到画布上，新节点会带上默认设置。
3. 把上一个节点的输出端口连到新节点的输入端口。
4. 选中节点，在属性面板中填写设置。

大多数算子只有一个输入和一个输出。部分算子会提供额外端口：

- **条件判断** 为每条配置的路径提供一个输出，再加一个 **fallback** 回退输出。
- **元素是否存在** 提供 true 与 false 两个输出。
- 循环与错误处理算子会提供返回端口或回退端口。

端口在各算子页以及[工作流概念](concepts.zh-CN.md#端口分支与循环)中说明。

## 配置算子

属性面板与算子表单一一对应。多数节点底部都有这些通用区块：

- **输出变量名** — 这一步把结果写到哪里。按数据含义命名（`headline`），不要按算子命名（`text2`）。
- **禁用算子** — 跳过这个节点，但不用删除它。
- **超时** — 运行超过限制时让这一步失败；填 `0` 表示不限制。
- **出错时** — 重试、抛出错误、继续执行或走回退分支。
- **目标与成功条件** — 可选的可判定事实，供生成、校验与 AI 修复使用。
- **断点** — 调试模式下在这一步之前暂停。

任何接受 `{{...}}` 的文本字段都可以引用工作流变量，包括选择器、网址、文件名与 JSON 值。规则与边界见[变量与插值](concepts.zh-CN.md#变量与插值)。

## 运行、调试与查看日志

点击 **运行**（Ctrl+Enter）在当前浏览器中执行工作流。如果工作流是在别处生成的，首次运行可能会让你确认页面上下文。

- **日志** 面板列出本次运行以及每个算子一行。点击某一行可在画布上定位该算子。
- 出错的步骤会中止运行，除非它的 **出错时** 策略另有规定。
- 如果必填参数缺失，运行会在第一个缺参算子之前停止；日志会逐个列出。

打开 **调试模式** 后，运行会在每个带断点的算子前暂停。调试栏提供 **继续**、**下一步**、**停止**，**变量** 面板显示暂停处捕获到的变量值。也可以在节点上使用 **从此处运行**，从图的中间开始执行。

触发器算子上的可选运行设置：

- **保存执行日志** 把运行记录留在历史里。
- **完成时通知** 在运行结束时发送浏览器通知。
- **工作流目标** 记录最后一步之后要校验的成功条件。

## 保存、导出与导入

**保存** 会存储工作流。工作流标签页提供 **导出**：可以导出单个工作流、当前选中的多个工作流，或一个分组；结果都是 JSON 文件。**导入** 接受这些文件（包括分组导出），恢复工作流与分组，不会覆盖无关的工作流。

如果工作流包含云端算子或当前版本不可用的算子，导入后节点会保留在画布上，但无法运行；参见[状态图例](README.zh-CN.md#状态图例)。

## 第一个工作流

目标：打开一个页面，把标题读入变量，拼出一行报告并写入文本文件。

1. 在工作流标签页新建一个工作流，并在编辑器中打开。
2. 触发器保持 **手动** 即可。
3. 添加 **新建标签页**，连接 触发器 → 新建标签页，把网址设为 `https://example.com`。
4. 添加 **获取文本**，连接 新建标签页 → 获取文本，选择器填 `h1`，**输出变量名** 填 `headline`。
5. 添加 **设置变量**，连接 获取文本 → 设置变量。新增一行：变量名 `report`，值 `Headline: {{headline}}`。
6. 添加 **导出数据**，连接 设置变量 → 导出数据：
   - **要导出的数据**：Variable（变量）。
   - **变量名**：`report`。
   - **导出为**：纯文本。
   - **文件名**：`headline.txt`。
7. 点击 **运行**。第一次导出会弹出保存对话框；如果已在 设置 → 下载目录 中配置了目录，文件会直接写入该目录，不再询问。
8. 打开 `headline.txt`，确认内容为 `Headline: ` 加上页面的 `h1` 文本。

如果文本为空，查看「获取文本」这一步的日志：选择器匹配不到元素时它会直接失败，而不是静默导出一个空文件。
