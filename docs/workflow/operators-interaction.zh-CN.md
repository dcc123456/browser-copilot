# 交互算子

本页介绍直接操作页面的算子：点击、读取、输入、滚动和派发事件。每个算子都列出设置、输出以及 Browser Copilot 特有的行为。

定位器支持 CSS 选择器、XPath 表达式或可见文本，所有数据字段都支持 `{{variables}}`。步骤在运行所绑定的标签页上执行，不一定是你眼前激活的标签页。无法解析的引用会原样保留，并在运行日志中指明。通用的**描述**、**禁用此算子**、**超时**和**出错时**设置适用于整个节点，因此不在每个表格中重复。

<!-- operator:event-click -->

## 点击元素

点击定位器匹配到的第一个元素。[Automa 参考](https://www.goautoma.com/extension/docs/blocks/event-click.html)

### 设置

| 字段               | 类型     | 默认值        | 说明                                                                                   |
| ------------------ | -------- | ------------- | -------------------------------------------------------------------------------------- |
| 查找元素方式       | 下拉选择 | `cssSelector` | `cssSelector`、`xpath` 或 `text`。选择 `text` 时，选择器字段填叶子元素的完整可见文本。 |
| 选择器             | 文本     | —             | 目标元素的定位器，支持 `{{variables}}`。                                               |
| 选择多个元素       | 复选框   | 关闭          | 通用定位选项；点击仍然只作用于第一个匹配项。                                           |
| 等待选择器         | 复选框   | 关闭          | 点击前轮询等待元素出现。                                                               |
| 选择器超时（毫秒） | 数字     | `5000`        | 开启**等待选择器**后使用的轮询时长。                                                   |
| 执行时标记元素     | 复选框   | 关闭          | 运行时高亮目标，便于在编辑器中观察。                                                   |

### 输出

无输出。一个主输出端口；错误按算子的**出错时**策略处理。

### Browser Copilot 说明

- 目标被禁用或被其他元素遮挡时，点击会被拒绝；运行日志会指出遮挡元素，而不是穿透点击。
- 步骤在派发点击后即返回。如果点击触发了导航，请在其后接读取或等待，再依赖新页面。
- 需要处理链接目标时用**点击链接**；按钮和其他控件用本算子。

## 获取文本

读取一个或多个元素渲染出的文本，写入变量，并可按需写入数据表。[Automa 参考](https://www.goautoma.com/extension/docs/blocks/get-text.html)

### 设置

| 字段                | 类型     | 默认值        | 说明                                                             |
| ------------------- | -------- | ------------- | ---------------------------------------------------------------- |
| 查找元素方式        | 下拉选择 | `cssSelector` | `cssSelector`、`xpath` 或 `text`。                               |
| 选择器              | 文本     | —             | 要读取的元素的定位器，支持 `{{variables}}`。                     |
| 选择多个元素        | 复选框   | 关闭          | 读取全部匹配项并以数组输出，而不是只读第一个。                   |
| 等待选择器          | 复选框   | 关闭          | 读取前轮询等待元素出现。                                         |
| 选择器超时（毫秒）  | 数字     | `5000`        | 开启**等待选择器**后使用的轮询时长。                             |
| 执行时标记元素      | 复选框   | 关闭          | 运行时高亮目标。                                                 |
| 正则                | 文本     | —             | 随算子保存；详见说明。                                           |
| 表达式旗标（flags） | 多选     | 无            | `g`、`i`、`m`，随正则一起保存。                                  |
| 文本前缀            | 文本     | —             | 保留该标记之后的文本。                                           |
| 文本后缀            | 文本     | —             | 保留该标记之前的文本。                                           |
| 包含 HTML 标签      | 复选框   | 关闭          | 返回元素的 `innerHTML`，而不是文本。                             |
| 使用 textContent    | 复选框   | 关闭          | 读取 `textContent`（包含隐藏节点），而不是渲染后的 `innerText`。 |
| 插入到数据表        | 复选框   | 开启          | 把读取结果写入数据表。                                           |
| 选择列              | 文本     | —             | 接收数据的列名。写入数据表时必填。                               |
| 添加额外行          | 复选框   | 关闭          | 随算子保存；详见说明。                                           |
| 额外行的值          | 文本     | —             | 仅在开启**添加额外行**时显示。                                   |
| 额外行列名          | 文本     | —             | 仅在开启**添加额外行**时显示。                                   |
| 赋值到变量          | 复选框   | 关闭          | 用自定义变量名发布结果。                                         |
| 变量名              | 文本     | —             | 自定义输出名；未勾选**赋值到变量**时忽略。                       |

### 输出

- **变量名**为空时写入 `{{lastText}}`，否则写入 `{{<name>}}`。两种情况下 `lastText` 都会更新。
- 开启**选择多个元素**时，值是一个字符串数组。
- 开启**插入到数据表**时，每次运行写入一个值，循环中每次迭代写入一行。再次写入同一列会替换该单元格。
- 一个主输出端口；错误按算子的**出错时**策略处理。

### Browser Copilot 说明

- 没有匹配到元素，或匹配到的文本全为空白时，步骤会失败，而不是发布空值。读取本来就是可选的场景请改用**元素是否存在**。
- **正则**和**表达式旗标（flags）**会随导入的工作流保存，但当前构建不会应用。可用**正则变量**或 **JavaScript 代码**过滤结果。
- **添加额外行**及其两个字段同样只保存、不写入。
- 存在标记时，**文本前缀**和**文本后缀**会保留前缀之后、后缀之前的子串。
- 开启**插入到数据表**但没有填列名时，算子会记录一条提示并跳过数据表写入。

## 滚动元素

把页面或元素滚动到指定偏移量，或把元素滚动到可见区域。[Automa 参考](https://www.goautoma.com/extension/docs/blocks/element-scroll.html)

### 设置

| 字段                        | 类型     | 默认值        | 说明                                                  |
| --------------------------- | -------- | ------------- | ----------------------------------------------------- |
| 查找元素方式                | 下拉选择 | `cssSelector` | `cssSelector`、`xpath` 或 `text`。                    |
| 选择器                      | 文本     | `html`        | `html` 或 `window` 滚动页面；其他定位器滚动对应元素。 |
| 选择多个元素                | 复选框   | 关闭          | 通用定位选项；只滚动第一个匹配项。                    |
| 等待选择器                  | 复选框   | 关闭          | 滚动前轮询等待元素出现。                              |
| 选择器超时（毫秒）          | 数字     | `5000`        | 开启**等待选择器**后使用的轮询时长。                  |
| 执行时标记元素              | 复选框   | 关闭          | 运行时高亮目标。                                      |
| 横向滚动                    | 数字     | `0`           | 横向目标位置（像素）。                                |
| 纵向滚动                    | 数字     | `0`           | 纵向目标位置（像素）。                                |
| 滚动到可见                  | 复选框   | 关闭          | 忽略偏移量，把元素滚动到可见区域。                    |
| 平滑滚动                    | 复选框   | 关闭          | 平滑动画滚动，而不是立即跳转。                        |
| Increment horizontal scroll | 复选框   | 关闭          | 把**横向滚动**视为相对当前位置的增量。                |
| Increment vertical scroll   | 复选框   | 关闭          | 把**纵向滚动**视为相对当前位置的增量。                |

### 输出

无输出。一个主输出端口；错误按算子的**出错时**策略处理。

### Browser Copilot 说明

- 使用默认的 `html` 选择器时滚动文档；使用 `window` 时同样滚动页面。只有在需要移动某个滚动容器时才填写具体元素选择器。
- 未勾选增量选项时，数值会作为目标位置传给 `scrollTo`，因此小于当前位置的值会向回滚动。
- **滚动到可见**优先于偏移量，并忽略增量选项。

## 点击链接

跟随链接元素，并可把目标地址放到新标签页打开。[Automa 参考](https://www.goautoma.com/extension/docs/blocks/link.html)

### 设置

| 字段               | 类型     | 默认值        | 说明                                         |
| ------------------ | -------- | ------------- | -------------------------------------------- |
| 查找元素方式       | 下拉选择 | `cssSelector` | `cssSelector`、`xpath` 或 `text`。           |
| 选择器             | 文本     | —             | 链接元素的定位器，支持 `{{variables}}`。     |
| 等待选择器         | 复选框   | 关闭          | 点击前轮询等待链接出现。                     |
| 选择器超时（毫秒） | 数字     | `5000`        | 开启**等待选择器**后使用的轮询时长。         |
| 执行时标记元素     | 复选框   | 关闭          | 运行时高亮目标。                             |
| 在新标签页打开     | 复选框   | 关闭          | 在新标签页打开目标，而不是在当前页跟随链接。 |

### 输出

无输出。一个主输出端口；错误按算子的**出错时**策略处理。

### Browser Copilot 说明

- 算子会先读取链接的目标地址，再执行点击。`_self` 链接在开启**在新标签页打开**时会通过新标签页打开，而不是替换当前页面。
- 步骤会等待目标标签页加载完成（最长约 15 秒）后才返回。
- 只跟随第一个匹配的链接；本算子隐藏了多元素选项。

## 填写表单

填写文本框、选择下拉选项、切换复选框或单选框，或读取表单控件的当前值。[Automa 参考](https://www.goautoma.com/extension/docs/blocks/forms.html)

### 设置

| 字段                       | 类型     | 默认值        | 说明                                                          |
| -------------------------- | -------- | ------------- | ------------------------------------------------------------- |
| 查找元素方式               | 下拉选择 | `cssSelector` | `cssSelector`、`xpath` 或 `text`。                            |
| 选择器                     | 文本     | —             | 表单控件的定位器，支持 `{{variables}}`。                      |
| 选择多个元素               | 复选框   | 关闭          | 通用定位选项；只使用第一个匹配项。                            |
| 等待选择器                 | 复选框   | 关闭          | 操作前轮询等待控件出现。                                      |
| 选择器超时（毫秒）         | 数字     | `5000`        | 开启**等待选择器**后使用的轮询时长。                          |
| 执行时标记元素             | 复选框   | 关闭          | 运行时高亮目标。                                              |
| 获取表单值                 | 复选框   | 关闭          | 读取控件，而不是写入。                                        |
| 赋值到变量                 | 复选框   | 关闭          | 用自定义变量名发布读取结果。                                  |
| 变量名                     | 文本     | —             | 开启**获取表单值**时必填。                                    |
| 表单类型                   | 下拉选择 | `text-field`  | `text-field`、`select`、`checkbox` 或 `radio`。               |

| 值                         | 文本     | —             | 要输入的文本，或下拉框的选项值，支持 `{{variables}}`。        |
| 清空输入框                 | 复选框   | 开启          | 输入前先清空字段。                                            |
| 选择选项方式               | 下拉选择 | `value`       | `value`、`first-option`、`last-option` 或 `custom-position`。 |
| 选项位置                   | 数字     | `1`           | `custom-position` 使用的从一开始的位置。                      |
| 输入延时（毫秒，0 为禁用） | 数字     | `0`           | 随算子保存；详见说明。                                        |

### 输出

- 开启**获取表单值**时：`{{<name>}}` 接收控件的原生值，变量名必填。
- 其他情况：无输出。
- 一个主输出端口；错误按算子的**出错时**策略处理。

### Browser Copilot 说明

- 文本值因为引用解析为空而变成空串时，算子会拒绝填写，避免误清空字段。
- **输入延时**会保存但不会生效；文本一次写入。
- 读取值保留原生类型：文本框为字符串，复选框和单选框为布尔值，多选下拉框为数组。
- `custom-position` 从 1 开始计数；按位置选择选项时不需要填写值。

## JavaScript 代码

在页面中执行一段 JavaScript 函数体，并保存其返回值。[Automa 参考](https://www.goautoma.com/extension/docs/blocks/javascript-code.html)

### 设置

| 字段               | 类型     | 默认值                                              | 说明                                                  |
| ------------------ | -------- | --------------------------------------------------- | ----------------------------------------------------- |
| 超时（毫秒）       | 数字     | `20000`                                             | 脚本的最长运行时间。                                  |
| 执行环境           | 下拉选择 | `website`                                           | `website` 在页面中运行；`background` 会保存但未实现。 |
| JavaScript 代码    | 多行文本 | `console.log("Script started");\nautomaNextBlock()` | 函数体，用 `return` 返回结果。                        |
| 在每个新标签页执行 | 复选框   | 关闭                                                | 随算子保存；详见说明。                                |
| 页面加载前运行     | 复选框   | 关闭                                                | 随算子保存；详见说明。                                |
| 预加载脚本         | 列表     | 空                                                  | 每项包含地址和类型（`script` 或 `style`）。           |
| 执行后移除         | 复选框   | 关闭                                                | 针对每个预加载项。                                    |

### 输出

- `{{lastResult}}` 始终接收脚本的返回值，或传给 `automaNextBlock()` 的值。
- 通过 `automaSetVariable()` 或直接给 `variables` 赋值写入的变量会合并到本次运行。
- 页面执行环境捕获的控制台输出会写入运行日志。
- 一个主输出端口；错误按算子的**出错时**策略处理。

### Browser Copilot 说明

- 页面执行环境提供 `automaNextBlock()`、`automaSetVariable()`、`automaRefData()` 和 `automaResetTimeout()`。
- 脚本按函数体执行，可写 `return`，不是独立程序。`automaNextBlock()` 会提前结束脚本并覆盖返回值。
- **执行环境**、**在每个新标签页执行**、**页面加载前运行**和**预加载脚本**会随工作流保存，但当前构建不会应用；脚本始终在当前页面运行。
- 空脚本会报错，抛出异常的脚本也会报错。重试或回退由节点的**出错时**策略决定。

- 页面需要精确配置的原生事件或其他事件对象时，请改用 **JavaScript 代码**。

无输出。一个主输出端口；错误按算子的**出错时**策略处理。

### Browser Copilot 说明

- 此算子只是上下文占位。执行器会把选中的框架写入运行日志，但不会改变驱动的框架上下文，后续步骤仍通过页面内核解析元素。
- 不要依赖它在运行时进入 iframe；它既不会聚焦框架，也不会限制后续定位器的范围。
- 导入工作流中的**查找元素方式**会被忽略，因为表单只提供一个选择器输入框。

## 上传文件

从选择器、工作流变量、最新下载或指定路径，把文件附加到上传控件。[Automa 参考](https://www.goautoma.com/extension/docs/blocks/upload-file.html)

### 设置

| 字段                       | 类型     | 默认值        | 说明                                                               |
| -------------------------- | -------- | ------------- | ------------------------------------------------------------------ |
| 上传方式                   | 下拉选择 | `user-select` | `user-select`、`workflow-file`、`latest-download` 或 `file-path`。 |
| 文件类型                   | 文本     | —             | MIME 类型或扩展名，例如 `image/*,.pdf`。                           |
| 存放文件的变量             | 文本     | —             | `workflow-file` 的变量名；可存放 data URL、文件产物或产物数组。    |
| 下载目录内的文件路径       | 文本     | —             | `file-path` 的相对路径，支持 `{{variables}}`。                     |
| 文件名模式                 | 文本     | —             | `latest-download` 用于挑选最新匹配文件的通配符。                   |
| 没有匹配文件时让我手动选择 | 复选框   | 关闭          | 没有匹配下载时回退到文件选择器。                                   |
| 查找元素方式               | 下拉选择 | `cssSelector` | `cssSelector` 或 `xpath`。                                         |
| 选择器                     | 文本     | —             | 上传控件的定位器，支持 `{{variables}}`。                           |
| 允许多文件                 | 复选框   | 关闭          | `latest-download` 和 `file-path` 下隐藏。                          |
| 上传前等待目标选择器       | 复选框   | 关闭          | 附加前轮询等待控件出现。                                           |
| 选择器超时（毫秒）         | 数字     | `10000`       | 开启**上传前等待目标选择器**后使用的轮询时长。                     |
| 验证文件已进入上传控件     | 复选框   | 开启          | 附加后检查控件，文件缺失时失败。                                   |

### 输出

- `{{lastUploadResult}}` 始终接收 `{ nodeId, selector, sourceMode, count, files? }`，描述控件和已附加的文件。
- 本算子没有自定义输出变量字段。
- 一个主输出端口；错误按算子的**出错时**策略处理。

### Browser Copilot 说明

- `user-select` 在运行时显示 Browser Copilot 自己的文件卡片；`workflow-file` 读取上游步骤已经产出的文件；`latest-download` 在设置的下载目录及其子目录中查找最新匹配文件；`file-path` 指定这些目录下的一个相对路径。
- **验证文件已进入上传控件**默认开启。控件报告的文件数量不足或 MIME 类型不符时，步骤会失败。
- 目标必须是文件输入框，或页面内核能关联到文件输入框的控件；否则步骤会失败，而不是静默跳过。
- 结果对象始终写入 `lastUploadResult`，后续步骤直接引用即可。

## 按键

向当前焦点控件或指定元素发送单个按键或组合键。[Automa 参考](https://www.goautoma.com/extension/docs/blocks/press-key.html)

### 设置

| 字段             | 类型     | 默认值      | 说明                                                                 |
| ---------------- | -------- | ----------- | -------------------------------------------------------------------- |
| 目标元素（可选） | 文本     | —           | 需要先聚焦的元素的 CSS 选择器或 XPath。                              |
| 操作             | 下拉选择 | `press-key` | `press-key` 输入单个按键或组合键；`multiple-keys` 显示自由文本字段。 |
| 按键             | 文本     | —           | 按键或组合键，例如 `Enter`、`a` 或 `Control+A`。                     |
| 按键             | 多行文本 | —           | `multiple-keys` 的自由文本；两个字段写入同一个按键字符串。           |
| 按压时长（毫秒） | 数字     | `0`         | 随算子保存；详见说明。                                               |

### 输出

无输出。一个主输出端口；错误按算子的**出错时**策略处理。

- 组合键用 `+` 连接，例如 `Control+Shift+Enter`。

## 创建元素

向页面注入 HTML、CSS 和可选的 JavaScript。[Automa 参考](https://www.goautoma.com/extension/docs/blocks/create-element.html)

### 设置

| 字段               | 类型     | 默认值        | 说明                                                             |
| ------------------ | -------- | ------------- | ---------------------------------------------------------------- |
| 查找元素方式       | 下拉选择 | `cssSelector` | `cssSelector`、`xpath` 或 `text`。                               |
| 选择器             | 文本     | `body`        | 目标元素，支持 `{{variables}}`。                                 |
| 等待选择器         | 复选框   | 关闭          | 注入前轮询等待目标出现。                                         |
| 选择器超时（毫秒） | 数字     | `5000`        | 开启**等待选择器**后使用的轮询时长。                             |
| 插入元素           | 下拉选择 | `after`       | `before`、`after`、`prev-sibling`、`next-sibling` 或 `replace`。 |
| 页面加载前运行     | 复选框   | 关闭          | 随算子保存；详见说明。                                           |
| HTML               | 多行文本 | —             | 要创建的标记，支持 `{{variables}}`。                             |
| CSS                | 多行文本 | —             | 注入页面的样式。                                                 |
| JavaScript         | 多行文本 | —             | 针对每个新建元素运行的脚本。                                     |
| 预加载脚本         | 列表     | 空            | 每项包含地址和类型（`script` 或 `style`）。                      |

### 输出

无输出。一个主输出端口；错误按算子的**出错时**策略处理。

### Browser Copilot 说明

- 执行器会转发 HTML、CSS 和 JavaScript，但不会转发目标选择器或**插入元素**。新建的标记会追加到 `document.body`，CSS 会作为样式元素加入页面。
- **页面加载前运行**和**预加载脚本**会保存，但当前构建不会应用。
- JavaScript 针对每个新建元素运行一次，`this` 指向该元素，并可通过 `automaRefData()` 读取变量。
- 由于目标选择器被忽略，此算子适合在页面末尾添加横幅、浮层或辅助元素，不适合插入到某个具体节点旁边。
