# v0.6.15 更新说明（自 v0.6.14 以来 / Changelog since v0.6.14）

> 本次提供**三种安装包**，按需下载：
>
> - `browser-copilot-0.6.15-ocr.zip` —— **Chrome 完整版**：内置本地 OCR（Tesseract.js），工作流 **OCR 识别**算子、离线验证码识别开箱即用。
> - `browser-copilot-0.6.15-no-ocr.zip` —— **Chrome 精简版**（约小 98%）：不含 OCR 引擎与语言模型，其余功能完全一致；OCR 算子置灰不可用，图片文字仍可通过视觉模型识别（模型设置 → 图片识别模型）。
> - `browser-copilot-0.6.15-firefox.xpi` —— **Firefox 版**（需 Firefox 128+）：由同一套源码构建，功能与精简版一致（Firefox 无 offscreen 文档，本地 OCR 不可用）；安装方法见下方「Firefox 安装」。
>
> Three packages ship this time: the usual two Chrome builds plus a Firefox
> 128+ build, built from the same sources and feature-identical to the lite
> Chrome build (local OCR is unavailable on Firefox).
>
> **Firefox 安装**：
>
> 1. **临时试用**（所有 Firefox 128+）：地址栏打开 `about:debugging#/runtime/this-firefox`，点「临时载入附加组件」，选择下载的 `.xpi`；重启浏览器后需重新载入。
> 2. **长期使用**（开发者版 / Nightly / ESR）：`about:config` 里把 `xpinstall.signatures.required` 设为 `false`，再到 `about:addons` → 右上角齿轮 → 「从文件安装附加组件」，选择该 `.xpi`。正式版 Firefox 只接受已签名扩展。
>
> **Installing on Firefox**: open `about:debugging#/runtime/this-firefox` and use
> "Load Temporary Add-on" with the `.xpi` (temporary, works on any Firefox
> 128+). For a permanent install, use Developer Edition / Nightly / ESR with
> `xpinstall.signatures.required` disabled in `about:config`, then
> `about:addons` → gear → "Install Add-on From File". Regular Firefox only
> installs signed add-ons.

## 🎯 v0.6.15

这一版围绕**让 agent 更可控、更耐用**：AI 算子节点可以逐个开关技能与工具，九个会改动页面之外状态的工具被彻底禁用；选中的页面元素可以直接交给本地 agent 去点击或填写；面板里的长对话不再因为轮次预算或重复失败而半途停住。

### 🧠 AI 算子：每个节点自己决定开哪些技能和工具

- **表单里多了一个「技能与工具」折页**：工具默认全部开启，可逐个关闭；技能默认关闭，按需开启。关闭的项会从模型请求里移除——被关工具的参数 schema、被关技能的目录行都不会再发给模型，因此能实打实降低 token 消耗。
- **新老工作流区别对待**：本次更新后**新建**的 AI 算子节点默认不开启任何技能；**之前已经建好**的节点保持全部技能开启，行为不变。由模型生成的节点同样以「空技能列表」起步。
- **关闭的技能调不动**：技能被关闭后，即使模型尝试用 `use_skill` 召唤它也会被拒绝并收到明确提示，可选项列表里也不再出现。
- **九个工具对 AI 算子彻底禁用**：关闭标签页、钉住标签页、取消钉住标签页、保存内容到文件、创建/更新技能、列出定时任务、创建定时任务、提交执行计划、把子任务委派给智能体——这些操作要么改的是页面之外的状态，要么需要真人现场批准，AI 算子既没有人可问、也没有回滚手段。它们现在**不会出现在表单里**，运行时也会被**硬性拒绝**，任何工作流、任何一次运行都一样。
- **完成契约写进提示词**：节点提示词明确要求「只有不带任何工具调用的回复才算答案」，并禁止为了复查结果而反复调用工具。

### 📄 选中的元素直接交给本地 agent

- **选中即记录**：用准星复制元素时，除了写剪贴板，还会把该元素的 CSS 选择器、标签名、可见文本和截断后的 HTML 记到后台，按标签页保存在会话存储里。
- **新工具 `read_selected_element`**：本地 agent（含 MCP）可以把最近一次选中的元素读回来，结果里直接带一个可用的 `target`，拿去 `click` / `fill` 即可；如果选完之后页面已经跳转，结果会标记为 `stale`，而不是把旧元素误当成当前页面。
- **设置里可关**：它和普通读取工具一样列在设置的工具列表里，可以单独关闭。
- **准星改成无卡片模式**：复制模式下只剩遮罩和高亮，点一下即复制并关闭。设置里的「只选不复制」开关打开后，第一次点击只选中并记录元素、高亮停留在所选元素上，再点一次或按 Esc 才退出——先圈出元素、再让本地 agent 去读它。
- **工作流编辑器的取元素不受影响**：无卡片只作用于网页上的准星，编辑器里的取元素仍保留卡片。

### ⏱ 长对话不再半途而废

- **按批继续，而不是到点就停**：面板对话把「最大动作步数」当成一批，用完一批就报告进度并接着开下一批，最多十批，长任务能走到结果，而不是做到一半就结束。无人值守运行和子代理仍保持单轮硬上限。
- **每个检查点都续上上下文**：每开一批都会重新挂上上下文压缩和超长重试，收尾阶段的「关工具总结」只保留在绝对上限处兜底。
- **不再播报步数**：对话记录里不再出现「已执行 N 步」之类的计数；即使真的到达上限，也只会给一条不含计数的本地化结束原因。
- **重复且无法改变的失败会被熔断**：同一个工具连续三次因为页面策略、权限这类「重试也不会变」的原因失败，本轮就不再允许调用它；可重试的错误不受影响。面板对话的轮次预算耗尽时，会补一次关闭工具的收尾，总结进展、阻塞点和下一步，并把这条答复保存下来，而不是让面板一声不响地停住。

### 🐛 修复

- **只读模式看不到图片**：只读的 AI 算子节点面对图片或验证码时，图片识别和截图被当成了「动作」而隐藏/拒绝，结果整轮只能对文本快照空转、最后没有答案。现在观察类工具不受只读限制，提示词也会直接指向图片识别。
- **两个页面按钮不能一起拖**：以前只有按住插件圆形按钮才能拖动整窗，按住准星没有任何反应。现在按住任一按钮都能拖动整个悬浮窗；没有越过 4px 阈值的按压仍然是点击。
- **旧版本残留的准星**：扩展更新前注入的准星脚本无法自行归位，会在圆形按钮被拖走时孤零零留在角落。现在窗口挂载时会丢弃这类残留。
- **拖拽起手跳动**：拖拽锚点改为窗口盒，而不是会被悬停/按压缩放撑大约 1.6px 的按钮矩形，起手不再轻微跳一下。

## English summary

**v0.6.15** makes the AI-agent block controllable and makes long turns durable.
Every AI-agent node now has a "Skills & tools" fold-out: tools are on by
default and switched off individually, skills are off by default and switched
on individually — new nodes start with no skills, nodes saved before this
release keep every skill, and anything switched off is removed from the model
request (its schema or catalogue line), lowering token cost. Nine
state-changing tools (closing, pinning and unpinning tabs; saving content to a
file; creating or updating skills; listing and creating scheduled tasks;
presenting a plan; delegating to a sub-agent) are hidden from the form and
refused at dispatch for every AI-agent run. The node prompt now states that
only a tool-free reply counts as the answer. Picking an element with the
crosshair also records it for the local agent, and the new
`read_selected_element` tool returns it with a ready target for `click` /
`fill`, flagged stale after a navigation. Chat turns now run their round
budget in batches (up to ten) instead of stopping halfway, report no step
counts, get a persisted tools-off wrap-up when the budget runs out, and refuse
a tool that keeps failing for an unchangeable reason.

- **AI-agent capabilities**: a "Skills & tools" fold-out on the node form;
  tools on unless switched off, skills off unless switched on (legacy nodes
  keep every skill, generated nodes start empty); disabled items leave the
  model request and disabled skills cannot be summoned via `use_skill`. Nine
  state-changing tools are not offered to AI-agent blocks at all — hidden in
  the form and hard-denied at dispatch. The prompt requires a tool-free reply
  as the answer.
- **Picked element → local agent**: a pick records selector, tag, text and
  capped HTML per tab; `read_selected_element` returns that record with a
  usable `target`, marks it `stale` after navigation, and can be switched off
  in Settings. Copy mode is card-less (one click copies and closes), and the
  former hide-card switch is now "select without copying": the first click
  only selects and records, the highlight stays, and a second click or Escape
  dismisses. The workflow editor's picker keeps its card.
- **Durable long turns**: a panel turn treats the max action steps as one
  batch and continues for up to ten batches, re-arming compaction and the
  over-length retry at each checkpoint; unattended runs and sub-agents keep
  their single cap. Step counts are no longer narrated. After three identical
  unchangeable tool failures the tool is refused for the rest of the turn, and
  an exhausted budget gets one tools-off completion that is persisted.
- **Fixed**: image recognition and screenshots are no longer withheld in
  read-only turns, so an image or captcha target is readable; either page
  button now drags the whole floating window (a press under 4 px stays a
  click); a crosshair left behind by an older script is dropped on mount; drags
  anchor on the window box, removing the slight jump at drag start.
