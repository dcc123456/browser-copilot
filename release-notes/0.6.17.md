# v0.6.17 更新说明（自 v0.6.16 以来 / Changelog since v0.6.16）

> 本次提供**三种安装包**，按需下载：
>
> - `browser-copilot-0.6.17-ocr.zip` —— **Chrome 完整版**：内置本地 OCR（Tesseract.js）。
> - `browser-copilot-0.6.17-no-ocr.zip` —— **Chrome 精简版**：不含 OCR 引擎，其余功能一致。
> - `browser-copilot-0.6.17-firefox.xpi` —— **Firefox 版**（需 Firefox 128+），功能与精简版一致。
>
> Three packages ship: the two Chrome builds (full OCR and lite) plus the
> Firefox 128+ build. All are built from the same sources.
>
> **Firefox 安装**：`about:debugging#/runtime/this-firefox` →「临时载入附加组件」选择 `.xpi`
> （所有 Firefox 128+）；长期使用见 README。
>
> **Firefox**: use "Load Temporary Add-on" in `about:debugging`; a permanent
> install needs Developer Edition / Nightly / ESR with signature enforcement off.

---

## 🆓 免费模型开箱即用

- **全新安装默认启用 Pollinations**：不需要 key、不需要配置，打开侧边栏即可聊天。
- 设置 → 模型服务新增一批免费 API provider：Gemini、Groq、Cerebras、SambaNova、
  Chutes、Hugging Face、ModelScope、Together、Novita、Nebius、Fireworks、
  OpenRouter `:free`、GitHub Models、智谱 GLM-4-Flash。
- 新 provider 都按 **OpenAI 兼容协议**核验：ModelScope / Novita / Nebius / Fireworks
  本机实测返回 OpenAI 形状的 JSON 错误；Together / Hugging Face 本机网络受限，但官方
  提供 OpenAI 兼容端点。
- 免费模型全部走 **HTTP API**：不打开网页、不新开窗口或标签页。

## 🏷 对话模型选择器里的 Free 标签

- 聊天输入框的模型下拉里，免费模型会带一个 **Free** 徽标；设置页的 provider 卡片也同步显示。
- 混合目录只标免费系列：OpenRouter 只有 `:free`、Together 只有 `-Free`、智谱只有
  `glm-4-flash` 会带标签，付费模型不会误标。
- 「免费可用」分组只放**直接免费用**（无需密钥）的 provider：目前是 Pollinations；
  有免费额度/每日赠送的 provider 留在「全部服务」。

## 🛍 工作流广场修复

- **应用 listing 时重新读取 `meta.json`**：以前卡片来自可能已过期的目录快照，而工作流文件
  已经重新拉取，导致带凭据或打包文件的 listing 可能用旧 meta 安装——`get-secret` 仍指向
  发布者的私有凭据 id，凭据本身却没有导入。现在应用/更新会从与正文同一版本读取 meta，
  凭据和打包文件始终匹配已安装的图。

## English summary

**v0.6.17** is about free models working out of the box.

- **Pollinations is the default provider** on a fresh install: no key, no setup.
- Settings → Models now includes free API presets for Gemini, Groq, Cerebras,
  SambaNova, Chutes, Hugging Face, ModelScope, Together, Novita, Nebius,
  Fireworks, OpenRouter `:free`, GitHub Models and Zhipu GLM-4-Flash. Each was
  checked for an OpenAI-compatible `/chat/completions` endpoint; the four that
  were reachable returned OpenAI-shaped JSON errors, and the other two are
  documented as compatible.
- **Free models carry a Free tag** in the composer's model picker and on
  provider cards. Mixed catalogs only tag their free family (OpenRouter `:free`,
  Together `-Free`, Zhipu `glm-4-flash`), so paid models are never mislabelled.
- The **Free to try** group holds only directly usable, keyless providers
  (Pollinations); quota-based providers stay in **All providers**.
- All free models use plain HTTP API calls — no web-chat tab or browser window.
- **Marketplace fix**: applying a listing re-reads `meta.json`, so credentials
  and bundled workflows match the installed graph.
