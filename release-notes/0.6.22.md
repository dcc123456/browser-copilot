# v0.6.22 更新说明（自 v0.6.21 以来 / Changelog since v0.6.21）

> 本次提供**三种安装包**，按需下载：
>
> - `browser-copilot-0.6.22-ocr.zip` —— **Chrome 完整版**：内置本地 OCR（Tesseract.js）。
> - `browser-copilot-0.6.22-no-ocr.zip` —— **Chrome 精简版**：不含 OCR 引擎，其余功能一致。
> - `browser-copilot-0.6.22-firefox.xpi` —— **Firefox 版**（需 Firefox 128+），功能与精简版一致。
>
> Three packages ship: the two Chrome builds (full OCR and lite) plus the
> Firefox 128+ build. All are built from the same sources.

---

## 🔧 自动更新恢复可用：0.6.20 / 0.6.21 的安装包版本号写错了

- 现象：在 0.6.20 / 0.6.21 上点**更新**，下载完成后报「下载的安装包不是有效的扩展压缩包」，重试也一样。
- 与网络无关：这两个发布包的文件名是 0.6.20 / 0.6.21，但包内 `manifest.json` 里的版本号**停在 0.6.19**
  （发布版本号在两处硬编码、漏同步）。更新器要求「包内版本 = 发布版本」，比对失败就整包拒绝。
- 0.6.22 的三种安装包版本号已全部修正。**卡在报错上的用户装一次 0.6.22 就能恢复**：从 0.6.19 / 0.6.20 /
  0.6.21 点更新都能直接完成；已经装过 0.6.21 坏包（`chrome://extensions` 里显示 0.6.19）的也走同一路径。
- 顺带两处防再犯：打包时校验 manifest 版本必须等于 `package.json`、no-OCR 标记必须与变体一致，不一致
  直接打包失败；万一再遇到版本不符的包，报错会说明「这个包是用另一个版本构建的，请手动安装」，不再
  误报成压缩包损坏。

## 🧹 聊天任务不再有轮次预算

- 聊天（chat）模式的任务不再有轮次预算：不会因为「20 轮用尽」暂停、弹续期或改预算的卡片；长任务会
  一直跑到模型给出结果，或者你点停止。
- 无人值守运行（定时任务、工作流 AI agent 块、委派子 agent）保留各自独立的轮次硬上限，到点直接停止
  ——不暂停、不续期、不询问。
- 升级时旧的「暂停」状态自动归一为进行中，不会再卡住。
- 顺带清掉残留：早先半自动回合留下的预算条与暂停卡片不会再飘在普通提问或新会话上；其他模式的预算
  输入改为点**调整预算**才展开；切换、新建、删除会话都会清空上一会话的预算条与暂停卡片。

## 🔑 不再有免密钥的默认 provider

- 删除 Pollinations 免密钥默认 provider：新装后 provider 列表为空，每个 provider 都要填自己的 key。
- 旧的 `default-pollinations` 配置在读取与 schema 迁移时清理。
- 仍然保留有免费额度的 provider 的「免费额度」徽标——免费额度不等于不用密钥。

## ⏹ 卡住的回合可以被停止

- 回合准备阶段（读对话记录、写会话索引、读页面）原来没有超时也无法取消：数据目录一旦无响应，面板会
  一直停在 preparing，**停止按钮按了也到不了**。
- 现在每一步都有 20 秒预算并跟随停止信号：超时会说明卡在哪一步；停止会像普通取消一样结束回合，不会
  留下占着对话的单回合锁。

## 📁 存储目录切换的三处修复

- **选择目录**：点击后立即打开系统目录选择器。之前先等 IndexedDB 句柄与权限查询，可能丢掉点击的临时
  授权，对话框根本不弹，设置项看起来像坏了。取消不再报失败；浏览器不支持该 API 时给出本地化提示。
- **目录不可读**：设置里新增「跳过迁移、直接更换」按钮。旧目录读不了、Chrome 又不再授权时不再死锁——
  点它放弃搬运数据的迁移，文件留在原处，然后换成新目录。
- **重连失败**：会明确报错，而不是让那一行静默不变。

## ⚙️ 设置页新增「故障恢复」

- 设置顶部新增「故障恢复」卡片，**重载插件**按钮（先确认）会重启扩展：任务停止、面板关闭、数据不动。
- 面板卡死时可以自己救一次，不用去 `chrome://extensions` 手动操作。
- 下载目录里的「打开系统下载文件夹」按钮删除（定位选择器已经能到达配置的目录）。

## ⚠️ 已知限制

- 自动更新只跟随已安装的变体（ocr / no-ocr）；在两种变体之间切换仍走手动替换。
- Firefox 版不会自更新；按「从文件安装」流程重装即可。
- 更新写入前会备份将被替换的文件，备份在新版本重新加载后、下一次打开面板时删除；当次没有目录权限时
  备份会保留并稍后重试。
- 0.6.20 / 0.6.21 的历史发布资产仍是旧版本号，请以 0.6.22 及以后为准。
