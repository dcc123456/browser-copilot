## ✨ v0.6.5

这一版的主线是**扩展第一次装进第二个浏览器**（Firefox 128+），以及"回合跑着的时候还能说话、任务跑到哪儿都看得见"。

### 🦊 Firefox 128+ 支持（新安装包）

- **同一套源码出三种包**：`pnpm build:firefox` 产出 `dist-firefox/`，发版时多出一个 `browser-copilot-0.6.5-firefox.zip`，安装方式与 Chrome 侧一样是"加载解压目录 / 临时载入"。
- **Firefox 侧的形态差异**：后台是**事件页**（event page）而不是 Service Worker；内容脚本各自打包成自包含的 IIFE；工具栏图标点击打开**侧栏**（`sidebar_action`），页内浮标的展开按钮同理。
- **没有 polyfill**：构建期把 `chrome` 直接别名到 Firefox 原生 `browser` 命名空间（`browser.*` 返回 Promise，正是代码里 `await chrome.…` 的用法），调用点一处未改；`typeof chrome` 守卫在两侧都成立。
- **能力差异明说**：AI 接管（依赖 `debugger`/CDP）在 Firefox 上不可用；本地 OCR 依赖 offscreen 文档，Firefox 也没有，因此该包不含 OCR；剪贴板读取走事件页降级路径；`moz-extension://` 页面与其他特权协议一样拒绝读取。
- **两套 manifest 同源**：Chrome / Firefox 两个组装器共用 `scripts/manifest-shared.ts`，并有锁步测试防漂移；`web-ext lint` 0 错误（剩余告警就是上面这些明确不支持的能力）。

### 🧵 回合进行中，把你的话递进去

- 过去"运行中想补充"只能 Stop 再发——那条路会悄悄丢掉"另存为工作流"卡片，还会把提问卡片悬在已经死掉的请求上。现在回合自带**补充队列**：你在它干活时键入的说明，会在下一个轮次边界（每个工具调用都已配好结果）被读入，并记成真正的 `role:'user'` 消息。
- 已经出了最终答复但队列里还有话？回合**继续做完**，不吞掉你的补充；它始终没读到的补充会带着提示回到输入框，而不是被丢掉。
- 确认 / ask_user / 计划卡片不再叠罗汉（只渲染最老的一张）；Stop 会宣告它遣散了哪些悬置交互，卡片不会活过等它的那个回合；生成弹窗新增 STOPPED 状态。

### 🪟 定时任务拥挤时，各自开窗

- 同一分钟响两个闹钟，过去都会落到最新插件窗口的同一个自动化页签上，两个任务轮流对同一页面动手。现在每次运行先**租一个窗口**：共享窗口空闲就照旧；被占用就开一个层叠摆放、不抢焦点的自有窗口，跑完自动关闭；全占满则 FIFO 排队、九分钟预算，等不到就**大声失败**而不是悄悄跳过。
- 设置里有 `maxConcurrentRunWindows`（1–6，默认 3）；任务面板会标出每次运行驱动的是哪个窗口，点击即可聚焦；窗口租约在 worker 被回收后依然能回收孤儿窗口。

### 📊 Token 用量面板（More → Tokens）

- 今天 / 7 天 / 30 天 / 首次使用至今四个窗口，趋势线与总览，再按**功能**（聊天、工作流生成、运行、AI 调试、自动修复、定时任务、上下文压缩、视觉、外部 API）和**会话 / 任务 / 工作流**双维分解；超出保留上限的行折叠成明确的"其他"而不是悄悄消失。
- 聚合在 worker 里完成，面板不接收全部原始记录；**清除用量**带确认。Runner 侧用同一套记账口径，另经 `GET /api/tokens/stats` 只读暴露——headless 花费按设计不进扩展面板。

### ⏰ 定时任务：一次性与链式

- **一次性任务**（`once`，本地时间）触发后立刻自我解除武装——"黄金时段发一条"不用再伪装成每日任务。
- **任务链**：子任务声明 `followsTaskId`，在提示或工作流变量里用 `{{upstream.<key>}}` 引用父任务最近一次成功输出（转接内容上限 512 字符）；引用在子任务**自己运行的那一刻**解析，所以可以先把后续任务建好、等输入出现。运行输出随运行日志一起持久化，作为跨任务交接。
- 任务列表改为**实时刷新**（订阅存储事件，无轮询），编辑改成对话框；单个技能行可以导出 / 导入 JSON。

### 🔁 面板关掉，回合照跑

- 最小化或关掉面板会让回合输出无人接收：重新打开时停在冻结快照上。现在回合把输出写进按会话的 **channel**——面板重新打开会自动接回（sink 换人）、重放断线期间的显示事件，待处理的确认 / 提问也仍然在等它。
- **Stop 现在点名会话**：一个面板可能在旁观多个会话的回合，Stop 只停屏幕上那一个。

### 🛠️ 其它修复

- **Stop 打断工具轮次不再毒化会话**：请求组装处修复 `tool_calls` 与结果配对，已被毒化的会话在下一次发送时自愈（此前每条后续消息都会 500）。
- **长对话裁剪不再删除用户消息**：以用户轮次为脊柱，轮次与结果同行，超预算也保你打过的话，而不是从最老的一端整轮丢。
- **JS 逃生舱解锁有据可依**：只有当"原生算子确实运行过且失败"有记录时，措辞为点击的 `javascript-code` 步骤才获准通过；没有记录维持拒绝，并写明解锁条件。
- 工作流编辑器：框选从节点上开始不再触发画布平移（Space 才平移画布）；`new-window` 块真正把运行（及其活动页签）重新指向它打开的新窗口，而不是"报告成功、后续步骤还在原窗口"。
- 技能 / 代理 YAML 解析器遇到非法列表项不再死循环拖垮 worker；通知块可勾选发送到飞书（复用定时任务的 webhook 配置，投递失败记错误行、不抛异常）；生成之前会把**已认证的工作流作为种子**提供给模型（只建议，不写节点）。

## English summary

**v0.6.5** — the extension installs into a second browser for the first time (Firefox 128+, `browser-copilot-0.6.5-firefox.zip`), and a running turn can finally be talked to.

- **Firefox 128+**: the same sources produce a third package. Event page instead of a service worker, sidebar instead of the side panel, content scripts as self-contained IIFE bundles, and `chrome` aliased to `browser` at compile time so no call site changed. AI takeover (`debugger`) and local OCR (offscreen document) are Chrome-only and absent on Firefox; both manifests are assembled from one shared source and a lockstep test guards the pair.
- **Mid-turn supplements**: a note typed while the model works is drained at the next round boundary as a real user turn; a turn that reaches its final answer with notes queued keeps working instead of finishing; unread notes return to the composer flagged; question cards no longer stack and Stop dismisses what it left hanging.
- **Run windows**: a scheduled run leases a window before it works — the shared plugin window when free, its own unfocused window when busy (closed when it settles), a FIFO queue with a nine-minute budget when saturated, failing loudly rather than skipping. `maxConcurrentRunWindows` (1–6, default 3) is a setting and the Tasks board shows which window each run drove.
- **Tokens dashboard** under More: today / 7 days / 30 days / all-time, a trend line, breakdowns by feature and by conversation, task or workflow, aggregated in the worker with a confirmed Clear. The Runner keeps the same ledger, exposed read-only over HTTP.
- **Scheduled tasks**: one-shot runs that disarm themselves, and task chains where `{{upstream.<key>}}` resolves at the child's own run time; the task list refreshes live and edits in a dialog; single-skill JSON export/import.
- **Reattachable turns**: a reopened panel resumes a running turn and replays what it missed; Stop names its conversation.
- **Fixes**: interrupted tool rounds heal at request time; transcript trimming keeps every user turn; the JS escape hatch unlocks only on a recorded native-operator failure; the editor's marquee starts over a node; `new-window` truly re-points the run; the YAML parser can't loop forever; notifications can post to Feishu; generation can seed from certified workflows.
