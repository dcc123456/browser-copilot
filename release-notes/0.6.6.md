# v0.6.6 更新说明（自 v0.6.5 以来 / Changelog since v0.6.5）

> 本次提供**三种安装包**，按需下载：
>
> - `browser-copilot-0.6.6-ocr.zip` —— **Chrome 完整版**：内置本地 OCR（Tesseract.js），工作流 **OCR 识别**算子、离线验证码识别开箱即用。
> - `browser-copilot-0.6.6-no-ocr.zip` —— **Chrome 精简版**（约小 98%）：不含 OCR 引擎与语言模型，其余功能完全一致；OCR 算子置灰不可用，图片文字仍可通过视觉模型识别（设置 → 图片识别模型）。
> - `browser-copilot-0.6.6-firefox.xpi` —— **Firefox 版**（需 Firefox 128+）：由同一套源码构建，功能与精简版一致（Firefox 无 offscreen 文档，本地 OCR 不可用）；安装方法见下方「Firefox 安装」。
>
> Three packages ship this time: the usual two Chrome builds plus a Firefox
> 128+ build, built from the same sources and feature-identical to the lite
> Chrome build (local OCR is unavailable on Firefox).
>
> **Firefox 安装**：
>
> 1. **临时试用**（所有 Firefox 128+）：地址栏打开 `about:debugging#/runtime/this-firefox`，点「临时载入附加组件」，选择下载的 `.xpi`；重启浏览器后需重新载入。
> 2. **长期使用**（开发者版 / Nightly / ESR）：`about:config` 里把 `xpinstall.signatures.required` 设为 `false`，再到 `about:addons` → 右上角齿轮 → 「从文件安装附加组件」，选择该 `.xpi`。正式版 Firefox 只接受已签名扩展。
>
> **Installing on Firefox**: open `about:debugging#/runtime/this-firefox` and use
> "Load Temporary Add-on" with the `.xpi` (temporary, works on any Firefox
> 128+). For a permanent install, use Developer Edition / Nightly / ESR with
> `xpinstall.signatures.required` disabled in `about:config`, then
> `about:addons` → gear → "Install Add-on From File". Regular Firefox only
> installs signed add-ons.

## ✨ v0.6.6

这一版的主线是**工作流编辑器把话说清楚**：一个节点能取多个凭证、条件分支看得见路径、提示词就能发起修复、变量不用背、框选不再卡住，另外多了一个「复制工作流」。

### 🔑 一个节点，取多个凭证

- 过去「获取凭证」算子只能记一条凭证，接两个 API 就得摆两个节点。现在它是一张**列表**：选凭证、给每一行起变量名（默认带出该凭证的 key，仍可改），下游按变量名引用。
- **一条凭证都没存的时候，按钮以前是不存在的**——面板只剩一句提示，点「添加凭证」像坏了。现在行列表和按钮始终在，空态只是多一句说明。
- 空行只存在于编辑器里，**永远不写进工作流**：没填凭证的行不构成一次取值请求。凭证**值**也从不落盘——存的是引用（`名称 · 字段名`），扩展运行时向 Runner 的 `BC_SECRET_*` 取值，Runner 不打印。
- 提示词同步收紧：敏感值能用普通输入算子就别塞凭证算子。

### 🌿 条件分支看得见路径

- 条件树支持给分支命名、追踪一个值走过的**路径**，`switch` 型流程不再看不出到底走了哪条；旧的存储形态读时自动迁移。
- 新增 **`elementValue`** 条件：直接比较元素里**实际持有的文本**，算子面板上配套一个取值选择器，不用手敲 `{{…}}`。

### 💬 回合跑着的时候，看得见

- 非聊天模式要跑多轮工具循环，面板此前全程静默。现在**推理内容实时流出**，每个工具调用标成人话意图，每步还有一只重新计时的秒表。
- 思考内容与最终回答分开存放，**不会混进回答，也不会写进对话记录**。

### 🩹 提示词就能修复，两处弹窗同一份日志

- 节点修复弹窗不再要求先贴日志——**写下期望，直接修**。
- 修复过程**实时输出详细日志**，失败中心弹窗与工作流回复弹窗**共用同一条事件流**：两处看到的进度一致，不用来回切。

### 📋 复制工作流

- 工作流列表新增「复制」：一条已保存的工作流复制成独立新记录，名字自动带 `（副本）`，无需改名对话框。
- 副本**不继承 revision 与修订历史**（它没经历过那些编辑），并同步重排触发器定时——否则副本的定时任务不会响。

### ⌨️ 字符串字段里的 `/`

- 所有接受字符串的算子参数，输入 `/` 即弹出变量菜单，不用再背 `{{name}}` 手打。
- 候选项**只列该节点运行时真能读到的**（上游变量、循环上下文、读取器别名）；选凭证会复用上游已有的 get-secret 节点，或在上游插入新节点。
- 菜单建在共用字段原语上，插值、校验与 Runner 宿主原样不动，**密钥值不进工作流、不进编辑器状态、不进 DOM**。

### 🛠️ 其它修复

- **空格框选终于能用**：按住空格拉框选、松开恢复拖动都正常。此前 React Flow 在本应用里收不到可信的空格按下事件（第三方库行为，已在设计文档中记录实测），现在手势由编辑器自己的按键状态驱动。
- **工作流 `ai-agent` 算子的花费记得住账**：它的回合带一个每节点 nonce 当会话 id，Tokens 面板既点不出名也打不开这条花费。现在该次运行的归属会传进嵌套回合，块内的视觉调用与上下文压缩一并继承。
- **目标说明不必藏起来**：每个算子面板都能就地展开「目标契约」的解释——逐步校验与 AI 修复到底在跑什么——展开说明不会误开/收起该区块。
- 变量菜单复用侧边栏既有的斜杠引擎（排序、匹配），未另造一套。

## English summary

**v0.6.6** — the workflow editor stops making you guess: one node can fetch several credentials, branch paths are legible, a prompt is enough to start a repair, and variables are one keystroke away.

- **Multi-credential get-secret**: the node holds a list — pick a credential, its key arrives as the variable name, stay editable. The rows and the add button now render with nothing stored (previously the button did not exist at all). Blank rows never reach the graph, and only the reference (`label · fieldKey`) is persisted: values come from `BC_SECRET_*` at run time and the Runner never logs them.
- **Condition paths**: branches can be named and a value's path through the tree is tracked; a new `elementValue` kind compares against the text an element actually holds, with a picker on the operator panel. Older shapes migrate on read.
- **Live progress in chat**: reasoning streams as it happens, every tool call is labelled with a plain-language intent, and each step ticks an elapsed clock. Thinking never folds into the answer or the persisted transcript.
- **Repair from a prompt, one shared log**: the node-fix dialog no longer needs a pasted log, and both repair dialogs stream the same detailed fix log from a single event stream.
- **Workflow duplication**: a saved workflow copies under a fresh id and an auto-generated `"(copy)"` name, with no inherited revision history and its trigger rescheduled in the same step.
- **`/` in string fields**: every operator string parameter opens a runtime-scoped variable menu. Picking a credential reuses a reachable get-secret producer or splices a node upstream; no secret value enters the workflow, editor state or the DOM.
- **Fixes**: Space box-select works and hands the canvas back on release (React Flow never sees a trusted Space keydown here, so the gesture runs off the editor's own key state); a workflow `ai-agent` block's turn is now attributed on the Tokens board; the goal contract is expandable in every operator panel.
