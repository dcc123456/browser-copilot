# v0.6.8 更新说明（自 v0.6.7 以来 / Changelog since v0.6.7）

> 本次提供**三种安装包**，按需下载：
>
> - `browser-copilot-0.6.8-ocr.zip` —— **Chrome 完整版**：内置本地 OCR（Tesseract.js），工作流 **OCR 识别**算子、离线验证码识别开箱即用。
> - `browser-copilot-0.6.8-no-ocr.zip` —— **Chrome 精简版**（约小 98%）：不含 OCR 引擎与语言模型，其余功能完全一致；OCR 算子置灰不可用，图片文字仍可通过视觉模型识别（设置 → 图片识别模型）。
> - `browser-copilot-0.6.8-firefox.xpi` —— **Firefox 版**（需 Firefox 128+）：由同一套源码构建，功能与精简版一致（Firefox 无 offscreen 文档，本地 OCR 不可用）；安装方法见下方「Firefox 安装」。
>
> Three packages ship this time: the usual two Chrome builds plus a Firefox
> 128+ build, built from the same sources and feature-identical to the lite
> Chrome build (local OCR is unavailable on Firefox).
>
> **Firefox 安装**：
>
> 1. **临时试用**（所有 Firefox 128+）：地址栏打开 `about:debugging#/runtime/this-firefox`，点「临时载入附加组件」，选择下载的 `.xpi`；重启浏览器后需重新载入。
> 2. **长期使用**（开发者版 / Nightly / ESR）：`about:config` 里把 `xpinstall.signatures.required` 设为 `false`，再到 `about:addons` → 右上角齿轮 → 「从文件安装附加组件」，选择该 `.xpi`。正式版 Firefox 只接受已签名扩展。
>
> **Installing on Firefox**: open `about:debugging#/runtime/this-firefox` and use
> "Load Temporary Add-on" with the `.xpi` (temporary, works on any Firefox
> 128+). For a permanent install, use Developer Edition / Nightly / ESR with
> `xpinstall.signatures.required` disabled in `about:config`, then
> `about:addons` → gear → "Install Add-on From File". Regular Firefox only
> installs signed add-ons.

## ✨ v0.6.8

这一版先解决一件拖了很久的事：**Chrome 解压版从此可以在面板里自己升级**，不用再手动下载、解压、替换。同时，画布多了分组块和撤销，AI 助手开始真的看着页面改流程；模型设置支持多模型与思考强度，工作流可以分组和整组导入导出，文件算子也补上了最新下载、Excel 解析与指定文件来源。

> **本次仍需手动安装 0.6.8**：自动更新器从 0.6.8 才开始存在。装好这一版后，之后的版本会在侧边栏弹出更新横幅，点一下即可完成。
>
> **This 0.6.8 still needs a manual install** — the updater first ships in this
> version. From the next release on, an update banner in the side panel will
> handle it.

### 🔄 扩展可以自己更新了（Chrome 解压安装）

- 侧边栏每 12 小时、以及扩展安装/启动时检查 GitHub 的 `/releases/latest`；有新版就显示更新横幅，横幅与弹窗的操作全部是图标按钮。
- 下载前校验 GitHub 给出的 **SHA-256 digest**，解压时校验路径与大小，拒绝越界或异常的包。
- **安装目录只需选一次**：首次更新时选择当初「加载已解压的扩展程序」用的目录，之后自动复用，不再弹选择框。
- 覆盖前先把每个将被替换的文件复制到安装目录下的 `browser-copilot-backup-<版本>-<时间>/`；旧的根清单存为 `manifest.json.bak`，所以备份目录**不会被 Chrome 认成第二个扩展**。确认新版本没问题后，该目录可以手动删除。
- 所有文件写完才写 `manifest.json`，写入中途失败时旧版本仍保持可运行。
- 更新完成后点「重新加载」生效；在重新加载之前，Chrome 会继续运行当前版本。
- Firefox 与商店安装**不会写文件**，只提供 Release 页链接。新代码只以本地安装包的形式运行，不做远程代码热加载。

### 🧠 多模型配置与思考强度

- 一个模型配置档现在能保存你添加过的**所有模型**，并标记当前使用的那一个；预置模型只作为建议，不会再把你抓取到的模型列表过滤成一条。
- 支持思考强度的厂商会多一个档位选择；**无法表达的档位直接置灰**，而不是给一个必然失败的选项。
- 厂商参数按**模型家族**解析：Qwen3.8 使用 `reasoning_effort` 且同一请求里拒绝 token 预算，较早的 Qwen3 继续使用预算；MiniMax 只有 M3.1-Flash 接受档位（且总是思考），M3 可以关闭但没有深度，M2 系列总是思考、不发送任何思考参数。
- 请求被厂商拒绝时，错误会以面板的语言重新表述，而不是原样抛出。

### 🧩 画布：分组块、撤销、真正看着页面的 AI 编辑

- 新增画布**分组块**：组内子节点保存在组自身的数据里，而不是图的顶层；引擎、完整性检查、运行校验、算子分类和连线逻辑都按这个结构处理。点击组名折叠、拖动组头排序，每张卡片都有「移入分组」菜单。
- **`Ctrl+Z` 撤销结构调整**：连线、删除、从面板拖入、拖动（一次手势只算一步）、自动布局，以及 AI 助手落下的每一批节点。没有重做；焦点在输入框或 CodeMirror 里时保留编辑器自己的撤销。
- 浮动 AI 助手先读取**当前页面的实时快照**再回答；可以直接使用你在页面上拾取的定位器，且它优先于 DOM 读取结果。
- 助手可以在选中步骤**之前**插入算子，也能对选中节点执行**编辑或替换**；缺少必需参数时会挂起这一批，提议在页面上实际走一遍再落地。
- 参数无法从 DOM 推导时，自动重试会带上一张截图——视觉模型直接看，其他模型则收到截图描述。
- 拾取器在捕获阶段接管 `pointerdown`/`mousedown`/`click`，并支持悬停 + Enter 提交，所以「点一下就关闭」的浮层不再让拾取失效。

### 🎯 元素选择器：锁定第 N 个匹配、按文本拾取、轮廓校验

- 一个宽泛选择器匹配到多行重复元素时，此前会原样提交，执行器于是静默操作**第一个**可见匹配。现在只要不是「匹配全部」的消费者，提交的选择器会被锁定到你瞄准的那个元素：唯一匹配保持原样，否则用强制的 `:nth-of-type` 路径，再退到绝对 `:nth-child` 路径（XPath 包成 `(expr)[n]`）。
- 命中多个时可以用步进器切换目标，Enter 提交锁定后的选择器；循环块与带 `multiple` 的消费者不锁定，继续拿宽泛选择器。
- **文本模式**用元素的可见文本填充选择器，并按内核的 tightest-holder 策略统计匹配数。
- **校验模式**会勾勒出全部匹配、在页面上停留一拍再回复，避免编辑器窗口盖上来后看不到结果。

### 🗂️ 工作流分组与批量导入导出

- Workflows 标签新增可折叠分组，复用已有的 `folderId`：分组只改成员关系，不会增加修订号或 `updatedAt`。
- 分组可以重命名、删除（成员回落到未分组），也能**整组导出**为包含成员工作流的信封文件，再原样导入。
- 勾选工作流即可批量导出；Data 标签的密钥与配置档使用同一套选择模型，用 `browser-copilot-data` 信封导入导出。
- 导入**总是新建**记录并使用全新 id，永远不会覆盖本地已有条目。

### 📄 文件算子：最新下载、Excel 解析、指定文件

- **`upload-file`** 可以取配置的或内置下载目录里**最新的匹配文件**（扩展侧），或这次运行记录到的下载（Runner 侧），并可选一个手动回退文件。
- **`parse-excel`** 把 `.xlsx`/`.csv` 解析成对象行加原始二维数组；解析器零依赖，扩展与 Runner 共用同一实现。
- 两个算子都能指定**一个具体文件**：以「下载相对路径」保存，通过递归列表选择。扩展侧能解析嵌套的 OPFS 路径；Runner 侧因为无头下载不保留目录，回退到记录的扁平文件名。

### 🧪 生成质量：失败证据与目标认证

- 失败算子调用不再只交回一条错误字符串，而是携带**证据包**：经共享失败码表分类的失败原因、有长度上限的内核消息、定位器解析结果、候选数量，以及**安全重跑边界**。
- 安全重跑边界是「最后一个没有提交任何东西的步骤」——在提交/发布之前重入会把同一动作做两次。它由草稿自身的节点推导，并随证据一起交给模型。
- 生成提示明确两条规则：已提交的步骤绝不重跑；由上游步骤导致的失败要点名，而不是重复同一尝试。
- 预保存试跑会把目标检查的**实际结果**（等级、未满足行、原因）记录下来并随保存/加载保留；保存卡片能区分「图本身坏了」与「跑完了但目标没达成」；在最后一步之前停止的试跑不构成证明，保持沉默。

### 🔧 其他改进

- 任务启用、飞书机器人及逐工具开关、编辑器的布尔字段、Runner 控制台的定时与触发开关，统一换成一个自带 `role="switch"` 的开关组件；多选与偏好类复选框保持原样。
- 聊天「保存为工作流」不再询问是否做一次 AI 复核，直接保存捕获到的步骤；历史回顾弹窗不受影响。
- 聊天流在中途断线后**自动重连**（最多 10 次固定间隔）：已经输出文字的回复从断点续传而不是重新开始；既没有 `[DONE]` 也没有结束原因就断开的流按同类瞬时故障处理；已经宣告的工具调用不会续传（半截参数无法安全续接）。full-auto 回显的 summary 块不再混进可见回复。
- Workflows 标签里「未分组」分区的折叠箭头此前点了没反应，现在有自己的折叠状态，折叠它不会动到上面的分组。

## English summary

**v0.6.8** — Chrome unpacked installs can now update themselves from GitHub
Releases, with digest verification, a reusable install folder, a pre-overwrite
backup and a reload prompt. The canvas gains group blocks and structural undo,
the floating assistant can edit and rewire the graph against the live page, the
picker pins the aimed match, workflows can be grouped and exported in batches,
providers support multiple models and per-model thinking effort, and the file
operators learn latest-download, Excel parsing and specified-path sources.

- **In-place self-update**: the panel checks GitHub's latest release every 12
  hours and on install/startup, verifies the asset's SHA-256 digest, extracts the
  ZIP with path and size validation, and overwrites the folder the extension was
  loaded from — asked for once, then reused. Every replaced file is copied into a
  timestamped `browser-copilot-backup-<version>-<time>` folder first, with the old
  root manifest stored as `manifest.json.bak` so the backup cannot be loaded as a
  second extension; `manifest.json` is written last so a failed write leaves the
  running version intact. Firefox and store installs get a release-page link
  instead. No remote code is hot-loaded: the package only runs after a reload.
  This release itself still needs a manual install, because the updater first
  ships in it.
- **Multi-model providers and thinking effort**: a profile stores every added
  model plus the one in use; levels a vendor cannot express are disabled. The
  vendor table resolves per model family — Qwen3.8 uses `reasoning_effort` and
  refuses a token budget, older Qwen3 keeps the budget; MiniMax accepts a level
  only on M3.1-Flash (which always thinks), M3 can be turned off but takes no
  depth, and M2 always thinks and receives no control. A rejected request is
  restated in the panel's language.
- **Canvas groups, undo and page-grounded AI edits**: a `blocks-group` block holds
  its children in its own data; groups fold by name, reorder by header drag, and
  every card can move into a group. Saving an edited workflow merges over the
  stored record, so its group, plan, table, `createdAt` and revision survive.
  `Ctrl+Z` walks structural history back (connections, deletions, drops, one entry
  per drag gesture, auto layout and assistant landings) with no redo, leaving
  native undo alone inside text fields. The assistant reads a live page snapshot
  first, accepts locators picked on the page, can insert before the selected step
  and edit or replace a node, and rides a screenshot on its automatic retry when
  a parameter cannot be derived from the DOM. The picker swallows clicks at the
  capture phase and can submit on hover plus Enter, so overlays no longer defeat
  it.
- **Picker pins the Nth match**: broad selectors matching repeated rows are pinned
  to the aimed element when the consumer is not an all-matches one — the plain
  selector when unique, otherwise a forced `:nth-of-type` path, then an absolute
  `:nth-child` path (XPath as `(expr)[n]`). A stepper switches matches, Enter
  commits, and loop blocks / `multiple` consumers keep the broad selector. Text
  mode fills the selector with visible text using the kernel's tightest-holder
  strategy; verify mode outlines every match before replying.
- **Workflow groups and batch import/export**: collapsible groups backed by
  `folderId` (membership only, no revision bump), group rename/delete with
  orphans falling back to ungrouped, and a group envelope that carries its member
  workflows. Checkbox selection drives batch export; the Data tab uses the same
  model for secrets and profiles. Imports always create fresh records and never
  overwrite local entries.
- **File operators**: `upload-file` takes the newest matching file from the
  configured/internal download folders or the run's recorded downloads, and
  `parse-excel` turns `.xlsx`/`.csv` into object rows plus the raw 2-D array via a
  dependency-free parser shared by both hosts. Both can target one concrete file
  stored as a download-relative path; the extension resolves nested OPFS paths
  and the Runner falls back to the recorded flat file name.
- **Generation evidence and goal certification**: failed operator calls carry a
  classified failure code, a bounded kernel message, locator resolution,
  candidate counts and the safe re-run boundary (the last step that committed
  nothing). The generation prompt states that a committed step is never re-run
  and that an earlier-step cause is named rather than repeated. The pre-save
  trial records the goal verdict and persists it across save/load; the save card
  distinguishes a broken graph from a run that left the goal unmet, and a trial
  stopped before the last step stays silent.
- **Other**: capability toggles share one `role="switch"` component; the
  chat save-as-workflow card no longer offers an optional AI review; chat streams
  reconnect up to ten times and resume an already-emitted reply, never resuming a
  half-announced tool call; the ungrouped section now collapses.
