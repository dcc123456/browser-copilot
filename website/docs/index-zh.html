工作流文档

Browser Copilot 工作流把反复进行的浏览器操作变成一张可运行、可调试、可复用的图：在画布上把算子连接起来，每个算子执行一步，变量负责在步骤之间传递数据。

本文档覆盖工作流调色板中出现的全部算子，以及 Browser Copilot 特有的行为：变量插值、数据表、循环、错误处理、下载、凭证，以及编辑器内置的 AI 能力。

第一次使用？先阅读快速上手完成第一个工作流，之后在搭建过程中随时查阅工作流概念。

本文档覆盖什么

调色板共有 63 个算子：

分类页 算子数 包含内容
页面交互 14 点击、读取、填写、滚动、脚本注入
浏览器 18 标签页、历史、截图、下载、OCR
通用 13 触发器、子工作流、HTTP、备注、AI
数据 11 变量、正则、排序、凭证、电子表格
条件控制 7 条件分支、元素判断、循环、循环断点

这 63 个算子里，58 个与 Automa 目录互通，5 个是 Browser Copilot 自有算子：ai-agent、ocr、set-variable、get-secret、parse-excel。

另外两页介绍平台而不是单个算子：快速上手与工作流概念。

字段说明以哪里为准

编辑器中的属性面板是节点设置的权威来源。每个算子页按属性面板的顺序描述相同字段，给出当前版本的默认值与表单上看不到的运行行为。

  • 中文页的算子名、标题与中文界面的调色板一致。
  • 设置名与中文属性面板的标签一致；只有当工作流 JSON 需要直接编辑时，页面才会提到存储键名。
  • 所有节点共享的工作流级设置——禁用、超时、错误处理、目标契约、断点——统一写在工作流概念中，不在每个算子页重复。

如果算子页与属性面板不一致，以属性面板为准，并请反馈这处差异。

算子总表

算子 用途 状态
页面交互
点击元素 点击定位器匹配到的第一个元素。
获取文本 读取一个或多个元素渲染出的文本，写入变量，并可按需写入数据表。
滚动元素 把页面或元素滚动到指定偏移量，或把元素滚动到可见区域。
点击链接 跟随链接元素，并可把目标地址放到新标签页打开。
属性值 读取元素的属性到变量，或把值写入属性。
填写表单 填写文本框、选择下拉选项、切换复选框或单选框，或读取表单控件的当前值。
JavaScript 代码 在页面中执行一段 JavaScript 函数体，并保存其返回值。
触发事件 在选中的元素上派发一个 DOM 事件。
切换框架/窗口 为后续步骤指定主窗口或某个 iframe 作为上下文。 占位实现
上传文件 从选择器、工作流变量、最新下载或指定路径，把文件附加到上传控件。
悬停元素 把指针移动到定位器匹配到的第一个元素上。
保存资源 原本用于下载媒体元素或直接链接，但此算子尚未实现。 尚未实现
按键 向当前焦点控件或指定元素发送单个按键或组合键。
创建元素 向页面注入 HTML、CSS 和可选的 JavaScript。
浏览器
当前标签页 把浏览器当前激活的标签页记录为工作流正在操作的标签页。
新建标签页 在新标签页中打开网址，并把该标签页设为工作流驱动的标签页。
切换标签页 按匹配模式、标题、位置或索引把已打开的标签页切到前台，并设为工作流操作的标签页。
新建窗口 打开新的浏览器窗口，并把工作流指向该窗口。
代理 在 Automa 中用于让浏览器流量经过代理，但在 Browser Copilot 的 Manifest V3 构建中不可用。 MV3 下不可用
后退 让工作流的标签页在浏览历史中后退一页。
前进 让工作流的标签页在浏览历史中前进一页。Automa 上游没有对应页面。
关闭标签页 关闭工作流正在驱动的标签页，并跟随浏览器在其位置激活的标签页。
截图 截取可见页面、整页或某个元素，并保存图像。
读取页面 读取当前标签页的可见文本、选中文本或 HTML，写入变量，并可按需写入数据表。Automa 上游没有对应页面。
浏览器事件 原本用于暂停到某个标签页、网络或下载事件发生，但此算子在当前构建中只是占位。 占位实现
处理对话框 安装处理器，用于接受或关闭页面的 JavaScript 对话框。
处理下载 等待浏览器下载并保存其详细信息。
保存到本地 把插值后的文本写入本地文件。Automa 上游没有对应页面。
刷新标签页 刷新工作流的标签页；填写网址时改为在该标签页打开该地址。
标签页网址 读取当前标签页或窗口中所有标签页的网址。
Cookie 获取、设置或删除浏览器 Cookie。
OCR 识别 对图片变量、页面元素或上一次页面快照运行本地 Tesseract.js OCR。Automa 上游没有对应页面。此算子仅存在于 Browser Copilot 中。 仅完整版可用
通用
触发器 工作流的入口。它保存工作流名称与运行设置、一个或多个启动方式，以及用于初始化运行变量的已声明输入。
执行工作流 把另一个已保存的工作流作为嵌套运行启动，结束后沿主输出继续。
延时 在下一步开始前按固定时长暂停运行。
导出数据 把本次运行的数据表或某个变量写入下载文件。
分组 把一组步骤打包成一个节点，让长画布更易读。分组按保存顺序运行内部步骤，然后从自己的输出继续。
剪贴板 把系统剪贴板或当前页面选中的文本读入变量，或把工作流中的文本写入剪贴板。
等待连接 先短暂停顿，让上一步触发的导航稳定下来，再等待正在操作的标签页报告加载完成。本版本等待的是标签页，而不是图中其他分支。
通知 显示桌面通知，也可以把同样的文本转发到飞书机器人。
便签 放在画布上的自由备注，用于说明工作流，不影响执行。该算子没有对应的 Automa 上游页面。
工作流状态 请求停止当前运行、另一个工作流或一组指定工作流。本版本中算子无法访问调度器，因此所有停止动作都会让步骤报错结束。
参数输入 在后续步骤运行前解析工作流已声明的输入。本版本不显示交互对话框：值来自运行作用域，缺失时用默认值补齐。
Webhook 向远程端点发送 HTTP 请求，并把响应解析到变量或数据表。
AI 智能体 读取可选的目标元素，把它和你的提示词一起交给可调用工具的 AI 智能体。智能体返回文本答案，在允许时还可以操作页面。Browser Copilot 独有算子。
数据
插入数据 向运行期的数据表追加记录，或把一个值写入变量。
删除数据 从数据表中删除列，或删除变量。
日志数据 把本次运行的日志收集为文本，写入变量，并可按需写入数据表的一列。
变量切片 截取字符串变量的一段，或数组变量的一个子数组。
变量自增 把数值变量加上固定步长；变量尚不存在时从零开始。
正则变量 用正则表达式处理文本变量，保留匹配结果或替换后的文本。
数据映射 重命名数据表行或变量数组中的字段。
排序数据 对数据表或变量中的数组排序，可按最多三个属性依次比较。
设置变量 在一步中写入一个或多个工作流变量。Browser Copilot 独有算子。
获取凭证 运行时把已保存的凭证字段复制到工作流变量。Browser Copilot 独有算子。
解析表格 把 .xlsx 或 .csv 表格读成对象数组与原始单元格二维数组。Browser Copilot 独有算子。
条件控制
重复任务 按固定次数运行所连接的分支，然后从 end 输出继续。
条件 自上而下依次判断命名的输出路径，运行走第一条所有条件都成立的路径；都不成立时走 fallback。
元素是否存在 定位器至少匹配到一个元素时走 exists 端口，一个都没有时走 not exists 端口。
While 循环 在条件成立期间重复运行所连接的分支，每轮开始前先判断条件。
循环数据 遍历数据表、数字区间、变量、JSON 数组或页面元素列表，把当前项写入 loopItem，把位置写入 loopIndex。
循环元素 遍历定位器匹配到的每个元素，并把当前元素的选择器写入 loopElementSelector。
循环断点 在循环体内的任意位置结束当前这一轮，或结束整个循环。

不可用的云端算子

目录中还认识 5 个云端算子。它们不会出现在调色板里，也没有本地执行器，因此本文档不把它们当作可用算子来写：

  • ai-workflow — 在 Automa 托管云端运行工作流。
  • google-sheets — 通过 OAuth 连接向 Google 表格追加行。
  • google-sheets-drive — 从 Google Drive 读取电子表格。
  • google-drive — 上传文件到 Google Drive。
  • block-package — 安装社区块包。

如果导入的工作流包含这些节点，画布会保留它们以便查看，但无法运行。

上游归属

Browser Copilot 的工作流 JSON 与 Automa 保持兼容，因此算子名、字段名以及相当一部分通用行为来自 Automa 项目。每个共享算子在 参考资源 一节给出对应的 Automa 文档链接。

这些页面的正文是依据本仓库行为为 Browser Copilot 撰写的，不是从 Automa 文档复制的。Browser Copilot 行为不同的地方，算子页会在 Browser Copilot 说明 中单独指出。

有 4 个目录算子没有上游文档页面，页面会明确标注：note、forward-page、save-local、read-page。5 个 Browser Copilot 自有算子一律标注为本地算子，不声称存在上游页面。

版本说明

本文档对应 Browser Copilot 0.6.8。新算子和新字段随功能一起加入；用旧版本保存的工作流，属性面板只显示该版本理解的字段，运行时仍会兼容旧的存储结构。
