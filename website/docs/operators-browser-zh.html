浏览器算子

这些算子处理标签页、窗口、导航、下载、对话框、Cookie 和页面截图。它们要么改变工作流所操作的页面，要么读取不属于 DOM 的浏览器状态。

所有数据字段都支持 {{variables}}。通用的描述、禁用此算子、超时和出错时设置适用于每个节点，因此不在下表中重复。当前执行器会保存但不生效的字段，会在各算子的说明中单独指出。

当前标签页

把浏览器当前激活的标签页记录为工作流正在操作的标签页。Automa 参考

设置

字段 类型 默认值 说明
禁用此算子 复选框 关闭 标准设置；运行时跳过此算子。

输出

  • {{lastActiveTab}} 接收当前标签页的 { id, url, title, active }。
  • 一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 算子只读取当前标签页，不会改变运行的标签页绑定。后续步骤需要移动到指定标签页时，请用切换标签页。
  • 本算子没有输出变量字段；结果始终写入 lastActiveTab。
  • 除了标准节点选项，它没有可编辑的设置。

新建标签页

在新标签页中打开网址，并把该标签页设为工作流驱动的标签页。Automa 参考

设置

字段 类型 默认值 说明
新标签页网址 文本 — 协议加地址。地址留空会打开空白标签页，支持 {{variables}}。
更新之前打开的标签页 复选框 关闭 复用上一个新建标签页打开的标签页，而不是再建一个。
等待标签页加载完成 复选框 关闭 等标签页进入 complete 状态后再继续。
设为活动标签页 复选框 开启 随算子保存；详见说明。
将标签页加入分组 复选框 关闭 随算子保存；详见说明。
使用自定义 User-Agent 复选框 关闭 随算子保存；详见说明。
User-Agent 文本 — 仅在开启自定义 User-Agent 时显示。
Tab zoom 滑块 1 随算子保存；详见说明。

输出

无输出。一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 标签页始终以活动状态创建，因此设为活动标签页目前不生效。将标签页加入分组、自定义 User-Agent 和 Tab zoom 会保存但不会应用。
  • 更新之前打开的标签页只复用本算子上一次创建的标签页，并在提供网址时切换其地址。如果该标签页已被关闭，则新建一个。
  • 步骤会把运行绑定到新标签页。如果未开启等待标签页加载完成，后续读取应使用等待选择器或自行轮询内容。

切换标签页

按匹配模式、标题、位置或索引把已打开的标签页切到前台，并设为工作流操作的标签页。Automa 参考

设置

字段 类型 默认值 说明
查找标签页方式 下拉选择 match-patterns match-patterns、tab-title、next-tab、prev-tab 或 tab-index。
匹配模式 文本 — 按通配符匹配标签页网址，例如 https://example.com/*。
标签页标题 文本 — 按子串匹配标签页标题。
无匹配时创建 复选框 关闭 按模式或标题找不到时新建标签页。
新标签页网址 文本 — 无匹配时创建使用的地址。
索引 数字 0 tab-index 使用的从零开始的标签页序号。
设为活动标签页 复选框 开启 除了切换工作流目标，还在浏览器中聚焦该标签页。

输出

无输出。一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 标签页索引从 0 开始，按运行所在窗口内标签页 id 升序排列，而不是视觉顺序。
  • 匹配模式是通配符。标签页标题按区分大小写的子串匹配。下一个标签页和上一个标签页相对于运行当前操作的标签页，并会循环。
  • 取消勾选设为活动标签页仍会把运行切换到匹配的标签页，只是不抢用户的焦点。
  • 无匹配时创建需要非空网址；没有网址时，找不到匹配项会让步骤失败。

新建窗口

打开新的浏览器窗口，并把工作流指向该窗口。Automa 参考

设置

字段 类型 默认值 说明
类型 下拉选择 normal normal、popup 或 panel。
网址（可选） 文本 — 要打开的地址，支持 {{variables}}。
窗口状态 下拉选择 normal normal、minimized、maximized 或 fullscreen。
设为无痕窗口 复选框 关闭 需要扩展获得无痕模式权限。
顶部 数字 0 屏幕位置；0 表示交给浏览器决定。
左侧 数字 0 屏幕位置；0 表示交给浏览器决定。
高度 数字 0 0 表示由浏览器决定。
宽度 数字 0 0 表示由浏览器决定。

输出

无输出。一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 只把网址传给浏览器。类型、窗口状态、无痕标志以及位置和尺寸字段会保存，但当前构建不会应用。
  • 运行所在的窗口和标签页会切换到新窗口，后续步骤都在其中执行。
  • 默认的 0 尺寸表示“由浏览器决定”，不是创建零尺寸窗口。

代理MV3 下不可用

在 Automa 中用于让浏览器流量经过代理，但在 Browser Copilot 的 Manifest V3 构建中不可用。Automa 参考

设置

字段 类型 默认值 说明
主机 文本 — 代理主机，例如 socks5://1.2.3.4:1080。
端口 数字 443 代理端口。
绕过列表 多行文本 — 逗号分隔的、不经过代理的主机。
清除所有代理 复选框 关闭 原本用于移除已配置的代理。
Scheme 文本 https 随算子保存；编辑器不显示此字段。

输出

无输出。步骤在产生值之前就会失败。

Browser Copilot 说明

  • Manifest V3 不支持。 chrome.proxy API 不可用，扩展也没有声明 proxy 权限，因此执行器直接抛错，而不是假装转发了流量。
  • 步骤失败是有意为之：一个用来隐藏网络出口的工作流，绝不能在直连时报告成功。
  • 保留这些设置只是为了让导入的 Automa 工作流不丢数据。修改它们无法让算子工作。
  • 请去掉此算子后运行工作流，或在浏览器或系统层面使用外部代理。

后退

让工作流的标签页在浏览历史中后退一页。Automa 参考

设置

字段 类型 默认值 说明
禁用此算子 复选框 关闭 标准设置；运行时跳过此算子。

输出

无输出。一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 导航发生在工作流正在驱动的标签页上，不一定是你眼前激活的标签页。
  • 步骤在发出导航后即返回；后续读取应轮询选择器，后续操作应开启等待选择器。
  • 标签页必须有上一条历史记录；否则浏览器会报错，步骤失败。

前进

让工作流的标签页在浏览历史中前进一页。Automa 上游没有对应页面。

设置

字段 类型 默认值 说明
禁用此算子 复选框 关闭 标准设置；运行时跳过此算子。

输出

无输出。一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 此算子是为了与后退配对而保留在 Browser Copilot 中的；Automa 上游文档没有对应页面。

关闭标签页

关闭工作流正在驱动的标签页，并跟随浏览器在其位置激活的标签页。Automa 参考

设置

字段 类型 默认值 说明
关闭 下拉选择 tab tab 或 window。
关闭当前标签页 复选框 开启 关闭运行当前的标签页。
匹配模式 文本 — 关闭当前标签页关闭时显示的网址匹配模式。
关闭所有窗口 复选框 关闭 选择 window 时显示。

输出

无输出。一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 当前构建会忽略关闭、匹配模式和关闭所有窗口：它始终关闭运行所在窗口的当前标签页。
  • 关闭后，运行会绑定到浏览器随后激活的标签页，后续步骤不会继续指向已失效的标签页。
  • 关闭窗口的最后一个标签页时，该窗口也会关闭。

截图

截取可见页面、整页或某个元素，并保存图像。Automa 参考

设置

字段 类型 默认值 说明
截图范围 下拉选择 page page（可见区域）、fullpage 或 element。
CSS 选择器 文本 — element 的定位器，支持 {{variables}}。
Image quality (100%) 滑块 100 JPEG 质量；仅在可见区域 JPEG 截图时显示并生效。
保存截图到本地 复选框 开启 把图像写入文件。
文件名 文本 — 保存文件的基础名称，支持 {{variables}}。
类型 下拉选择 png 保存可见区域截图时可选 png 或 jpeg。
插入截图到数据表 复选框 关闭 以 data URL 形式追加到指定列。
选择列 文本 — 开启插入截图到数据表时使用的列名。
赋值到变量 复选框 关闭 用自定义变量名发布图像。
变量名 文本 — 自定义输出名。

输出

  • 变量名为空时写入 {{lastScreenshot}}，否则写入 {{<name>}}。图像是 data URL。
  • 保存截图到本地成功时，{{lastScreenshotPath}} 接收文件名。
  • 开启插入截图到数据表时，data URL 追加到指定列。
  • 一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 整页和元素截图固定为 PNG。这两种模式选择 JPEG 会实际保存 .png 文件并记录一条警告；JPEG 质量只对可见区域截图生效。
  • 写入磁盘时，先使用设置的下载目录，再打开侧面板的保存对话框，最后是扩展存储中的无人值守目录 browser-copilot-downloads/。
  • 把截图存入数据列会让工作流的数据表变得很大；整页大图建议使用保存截图到本地。
  • 可见区域截图会在必要时恢复最小化窗口；截图失败时会给出浏览器底层错误。

读取页面

读取当前标签页的可见文本、选中文本或 HTML，写入变量，并可按需写入数据表。Automa 上游没有对应页面。

设置

字段 类型 默认值 说明
Read 下拉选择 text text（可见文本）、selection 或 html。
Element (optional) 文本 — 限定文本或 HTML 读取范围的 CSS 选择器；留空读取整个文档。
Max characters 数字 20000 返回字符串的上限；正文被截断时会记录一条提示。
赋值到变量 复选框 关闭 用自定义变量名发布结果。
变量名 文本 — 结果的自定义输出名。
插入到数据表 复选框 关闭 把结果写入数据表。
选择列 文本 — 接收结果的列名。

输出

  • 变量名为空时写入 {{lastReadPage}}，否则写入 {{<name>}}。两种情况下 lastReadPage 都会更新。
  • 开启插入到数据表时，每次运行写入一个值，循环中每次迭代写入一行。
  • 一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 此算子专属于 Browser Copilot，Automa 没有对应页面。
  • selection 会忽略元素范围，读取用户当前的选中内容。没有选中文本时只记录错误，不会让步骤失败。
  • html 返回限定元素的 outerHTML 或整个文档，并受 Max characters 限制。
  • 文本读取或限定元素的 HTML 读取结果为空时，步骤会失败，规则与获取文本一致。

浏览器事件占位实现

原本用于暂停到某个标签页、网络或下载事件发生，但此算子在当前构建中只是占位。Automa 参考

设置

字段 类型 默认值 说明
事件 下拉选择 tab:loaded 编辑器列表中的标签页、网络或下载事件。
超时（毫秒） 数字 10000 随算子保存；详见说明。
设为活动标签页 复选框 开启 仅标签页事件。
等待标签页网址 文本 — tab:loaded 使用的网址模式。
下载文件名查询 文本 — download:created 使用的文件名子串。

输出

无输出。执行器记录一条提示后立即返回。

Browser Copilot 说明

  • 占位实现。 执行器既不订阅浏览器事件也不等待；步骤一开始就立即完成。
  • 超时、设为活动标签页和两个过滤字段会保存，但没有任何效果。
  • 需要等待页面状态时，请用延时加读取或元素是否存在；需要拿到下载文件时，请用处理下载。

处理对话框

安装处理器，用于接受或关闭页面的 JavaScript 对话框。Automa 参考

设置

字段 类型 默认值 说明
接受对话框 复选框 开启 对 confirm() 对话框选择接受而不是取消。
提示文本（可选） 文本 — prompt() 的回答；仅在接受时显示。

输出

无输出。一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 算子会改写页面的对话框处理器，影响之后出现的对话框：confirm() 返回接受值，设置了提示文本时 prompt() 返回该文本，beforeunload 提示会被抑制。
  • 它不会关闭已经打开的 alert()，因为原生对话框阻塞页面时页面脚本无法运行。
  • 冻结或重定义了对话框函数的页面可能无法改写；步骤仍会报告成功，因此对话框很关键时请验证下一步操作。

处理下载

等待浏览器下载并保存其详细信息。Automa 参考

设置

字段 类型 默认值 说明
超时（毫秒） 数字 20000 查找匹配下载的时长。
文件下载 ID（可选） 文本 — 随算子保存；详见说明。
文件名（可选） 文本 — 与下载文件完整路径匹配的子串。
冲突时 下拉选择 uniquify 随算子保存；详见说明。
等待文件下载完成 复选框 开启 轮询直到出现匹配下载或超时。
赋值到变量 复选框 关闭 用自定义变量名发布记录。
变量名 文本 — 自定义输出名。

输出

  • 变量名为空时写入 {{lastDownload}}，否则写入 {{<name>}}。
  • 值是匹配项的 { id, filename, url }；超时内没有匹配时为 null。
  • 一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 匹配方式是文件名子串。没有填写文件名时，使用浏览器返回的最近一次下载。
  • 文件下载 ID和冲突时会保存但不使用；算子只记录元数据，不会重命名、移动或删除文件。
  • 没有找到下载不算错误：输出为 null，后续条件可以据此分支。

Cookie

获取、设置或删除浏览器 Cookie。Automa 参考

设置

字段 类型 默认值 说明
操作 下拉选择 get get、set 或 remove。
获取所有 Cookie 复选框 关闭 读取全部 Cookie，而不是一个指定名称的 Cookie。
使用 JSON 格式 复选框 关闭 以 JSON 描述 Cookie 操作；详见说明。
网址 文本 — Cookie 的网址。set 和 remove 必填。
名称 文本 — Cookie 名称。get、set 和 remove 均必填。
值（可选） 文本 — set 写入的值，支持 {{variables}}。
路径（可选） 文本 — 随算子保存；详见说明。
域名（可选） 文本 — 随算子保存；详见说明。
SameSite（可选） 文本 — 随算子保存；详见说明。
过期时间（秒，可选） 文本 — set 使用的过期时间；留空表示会话 Cookie。
仅 HTTP 复选框 关闭 随算子保存；详见说明。
安全 复选框 关闭 随算子保存；详见说明。
赋值到变量 复选框 关闭 用自定义变量名发布读取结果。
变量名 文本 — get 的自定义输出名。

输出

  • get：变量名为空时写入 {{lastCookie}}，否则写入 {{<name>}}，内容是 Cookie 值或空字符串。
  • get 且勾选获取所有 Cookie 时，变量接收 Cookie 对象数组。
  • set 和 remove：无输出。
  • 一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 只把网址、名称、值和过期时间传给浏览器 API。路径、域名、SameSite、仅 HTTP、安全、session 和 JSON 编辑器会保存，但当前构建不会应用。
  • set 和 remove 需要网址；remove 还需要名称。
  • 读取不存在的 Cookie 会写入空字符串而不是失败，使用前请先检查值。

OCR 识别仅完整版可用

对图片变量、页面元素或上一次页面快照运行本地 Tesseract.js OCR。Automa 上游没有对应页面。此算子仅存在于 Browser Copilot 中。

设置

字段 类型 默认值 说明
输入图片 下拉选择 page variable、element 或 page（上一次可见页面快照）。
图片变量（data URL / base64 / 链接） 文本 lastScreenshot variable 模式读取的变量。
CSS 选择器 文本 — element 模式读取的元素，可为 img、canvas 或无文本容器。
OCR 语言（留空 = 使用全局设置） 文本 — 用 + 连接的 Tesseract 语言代码，例如 eng+chi_sim。
识别前预处理图片（放大 + 增强对比度） 复选框 开启 预处理图片；失败时回退到原图。
输出变量（字符串类型） 文本 lastOcrText 接收识别文本的变量。

输出

  • 输出变量为空时写入 {{lastOcrText}}，否则写入 {{<name>}}。值始终是字符串。
  • 识别结果为空时步骤会失败，并给出截图、语言和预处理方面的诊断信息。
  • 一个主输出端口；错误按算子的出错时策略处理。

Browser Copilot 说明

  • 仅完整 OCR 构建可用。 无 OCR 版本不编译 Tesseract.js（OCR_SUPPORTED 为 false）；编辑器会禁用该算子，执行器也会拒绝运行。
  • OCR 使用 Tesseract.js 和本地语言数据在设备上运行，图片不会上传到任何地方。
  • 元素来源只使用 CSS 选择器。导入的查找元素方式会被忽略，XPath 表达式无法解析。
  • OCR 语言留空时使用全局的本地 OCR 语言设置。缺少语言包会让识别失败，而不会静默回退。
