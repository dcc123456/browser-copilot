数据算子

数据算子处理工作流在各步骤之间搬运的内容：运行期的数据表、单个变量，以及表格文件。它们只读写值，不操作页面。变量、插值、数据表与下载目录的通用规则见工作流概念；通用的描述、禁用此算子、超时和出错时设置适用于每个节点，下文不再重复。

插入数据

向运行期的数据表追加记录，或把一个值写入变量。Automa 参考

设置

字段 类型 默认值 说明
行类型 下拉选择 table table 填充某一列；variable 写入变量。该选择框没有标签，位于每一行的最左侧。
数据表列 文本 — 接收该值的列。仅 table 行显示；编辑器没有实时列清单，请直接填列 id 或列名。
变量名 文本 — 接收该值的变量。仅 variable 行显示。
值 文本 — 先做插值再写入，支持 {{variables}}。

输出

  • table 行把值写入该列在已有每一行上的单元格。数据表为空时会先建一行；它不会按条目新增行。
  • variable 行创建或覆盖同名变量。
  • 形如 {"sku": "A-1"} 的记录条目会被当作新行追加。生成的工作流使用这种形态，表单不会产生它。
  • 没有自己的输出变量。一个主输出端口。

Browser Copilot 说明

  • 存储的清单也可以是 JSON 字符串；导入的工作流使用这种形式，读取方式相同。
  • 若条目带有 action: "append"，值会拼接到变量当前值之后而不是覆盖。只有导入的节点会带该标记，表单始终覆盖。
  • 文件导入相关字段（filePath、isFile）为导入工作流保留，但本版本不应用；表单中也写明了本版本不支持文件导入。
  • 条目在插入数据弹窗中逐行编辑，可添加，每行右侧有删除按钮。

删除数据

从数据表中删除列，或删除变量。Automa 参考

设置

字段 类型 默认值 说明
数据来自 下拉选择 table 数据表 针对数据表；变量 针对一个变量。
列 下拉选择 [All columns] [All columns] 清空整张表；列 会展开一个文本框填写列 id 或列名。
列（名称） 文本 — 要从每一行移除的列。仅在选择 列 后显示。
变量名 文本 — 要删除的变量。变量 条目用它替代列字段。

输出

没有输出变量。一个主输出端口；运行日志会报告删除了多少列、多少个变量。

Browser Copilot 说明

  • 选择 [All columns] 会把 dataTable 换为空数组，行也会一并消失。删除具名列则保留行，只去掉该字段。
  • 每个条目占一行并带删除按钮；清单为空时什么也不做，日志会提示没有配置删除项。
  • 删除不存在的变量会被静默跳过；删除任何行都没有的列也会计为已处理。

日志数据

把本次运行的日志收集为文本，写入变量，并可按需写入数据表的一列。Automa 参考

设置

字段 类型 默认值 说明
工作流（工作流 id） 文本 — 保持为空。本版本只保留当前运行的日志；填写值会让该步骤失败。
赋值到变量 复选框 关闭 把日志文本写入指定变量。
变量名 文本 — 输出变量。开启赋值到变量后显示。
插入到数据表 复选框 开启 由算子保存。只有填写了列名时才会真正写入一行。
选择列 文本 — 接收这段日志的列，日志作为一行追加。表单要填入工作流 id 后才显示该字段。

输出

  • 开启赋值到变量时写入 {{<变量名>}}，内容为运行日志。
  • 插入到数据表开启且填写了列名时，追加一行 { <列>: <日志> }。
  • 不会写入 lastLog 之类的兜底变量。一个主输出端口。

Browser Copilot 说明

  • 日志文本是本次运行到目前为止产生的行，用换行连接；排在本节点之后的步骤不会包含在内。
  • 填写了工作流 id 会让步骤失败，并说明两个宿主都不保存历史运行日志。编辑器没有工作流列表，该 id 字段只是占位，请留空。
  • 日志同时会回显到运行日志，所以只想在运行记录里留个标记的节点可以两处输出都关闭。

变量切片

截取字符串变量的一段，或数组变量的一个子数组。Automa 参考

设置

字段 类型 默认值 说明
变量名 文本 — 要切片的变量，切片结果也写回它。
起始索引 复选框 开启 是否使用起始偏移。关闭表示从 0 开始。
起始索引（数值） 数字 0 片段开始的位置。
结束索引 复选框 关闭 是否使用结束偏移。关闭表示切到末尾。
结束索引（数值） 数字 0 片段结束的位置，不含该位置本身。

输出

  • 片段写回同一个变量；没有单独的输出变量名字段。字符串得到子串，数组得到子数组。
  • 一个主输出端口。

Browser Copilot 说明

  • 索引遵循 JavaScript slice 的语义：负数从末尾往前数，结束位置小于起始位置时结果为空。
  • 变量不存在，或值不是字符串/数组（例如数字、对象）时步骤会失败，而不是产出空字符串。
  • 只带 start / end 的导入节点仍可读取；旧式 end 没有对应开关时，视为启用结束索引。

变量自增

把数值变量加上固定步长；变量尚不存在时从零开始。Automa 参考

设置

字段 类型 默认值 说明
变量名 文本 — 要更新的数值变量。必填；留空会让步骤失败。
增量 数字 1 要加上的数值。该字段会插值，因此可以填上游步骤产出的 {{step}}。

输出

  • 更新后的同一个变量。运行日志输出 变量名 = 值。
  • 一个主输出端口。

Browser Copilot 说明

  • 变量不存在时按 0 起算，因此可以直接当循环计数器用，无需先初始化。
  • 当前值不是数值时会归零，因为计算出的 NaN 会被替换而不是保存。请保证该变量始终是数字。
  • 导入的节点可能带 incType: "multiply"，此时做乘法，且变量不存在时从 1 起算。表单没有提供该开关。

正则变量

用正则表达式处理文本变量，保留匹配结果或替换后的文本。Automa 参考

设置

字段 类型 默认值 说明
变量名 文本 — 要读取的变量，结果写回同一个变量。
Method 下拉选择 match Match value 收集命中项；Replace value 做替换。
替换为 文本 — 替换文本，支持插值。仅在 replace 时显示；留空表示删除命中内容。
正则 文本 — 正则表达式主体，不含两侧斜杠。必填。
表达式旗标（flags） 多选 无 g、i、m 三个复选框，按列表保存，运行时拼接。

输出

  • match 模式输出命中项的 JSON 文本，例如 ["id-1","id-2"]。变量里是字符串而不是数组；下游直接读 {{变量名}}，需要按下标取值时用 JavaScript 代码解析。
  • replace 模式输出替换后的字符串。
  • 结果写回同一个变量，没有单独的输出变量名字段。一个主输出端口。

Browser Copilot 说明

  • 不带 g 旗标时只收集第一个命中项；完全没有命中时值为 []。
  • 正则无效会让步骤失败，变量保持不变，避免下游静默读到旧值。
  • 节点里完全没有旗标字段时按 g 处理；显式存成空列表则表示不带旗标。
  • 只有替换为会插值；正则与旗标按字面使用。

数据映射

重命名数据表行或变量数组中的字段。Automa 参考

设置

字段 类型 默认值 说明
数据来源 下拉选择 table 数据表 读取 dataTable；变量 读取指定变量。
变量名 文本 — 源变量，数据来源选 变量 时显示。
源 文本 — 要改名的属性。每个源属性一行。
目标 文本 — 新的属性名。一个源可以挂多个目标：值会复制到每个目标，源键随后删除。
插入到数据表 复选框 关闭 由算子保存；本版本不应用（见说明）。
选择列 文本 — 由算子保存；本版本不应用（见说明）。
赋值到变量 复选框 关闭 把映射后的数组写入一个变量。
变量名 文本 — 输出变量，开启赋值到变量后显示。

输出

  • 映射后的数组；数据来源为 变量 时会写回该源变量。
  • {{lastMappedData}} 始终会拿到映射后的数组。
  • 开启赋值到变量时写入 {{<变量名>}}。
  • 一个主输出端口。

Browser Copilot 说明

  • 数据来源选 数据表 时，映射后的行不会写回数据表。请开启赋值到变量（或读取 {{lastMappedData}}）来保留结果。
  • 插入到数据表与选择列只是为了导入的工作流不丢设置而保存，本版本不会因此写入数据表。
  • 只重命名顶层属性。缺少源属性的行原样保留；目标名与源名相同时该条映射被忽略。
  • 映射清单在弹窗中编辑：左侧源，右侧每个源可添加一个或多个目标。

排序数据

对数据表或变量中的数组排序，可按最多三个属性依次比较。Automa 参考

设置

字段 类型 默认值 说明
数据来源 下拉选择 table 数据表 排序 dataTable；变量 排序指定变量。
变量名 文本 — 源变量，数据来源选 变量 时显示；排序结果写回它。
按项目属性排序 开关 关闭 关闭时直接比较条目本身；开启后显示属性行。
属性 1–3 文本 — 参与比较的属性名。最多三行。
排序方向 下拉选择 asc Ascending（升序）或 Descending（降序），每个属性各一项。
插入到数据表 复选框 关闭 由算子保存；本版本不应用（见说明）。
选择列 文本 — 由算子保存；本版本不应用（见说明）。
赋值到变量 复选框 关闭 同时把排序后的数组写入一个变量。
变量名 文本 — 输出变量，开启赋值到变量后显示。

输出

  • 排序后的副本：数据表来源会替换 dataTable；变量来源会覆盖源变量。
  • 开启赋值到变量时写入 {{<变量名>}}。
  • 运行日志报告首个排序属性与行数。
  • 一个主输出端口。

Browser Copilot 说明

  • 按项目属性排序关闭，或没有属性行时，直接比较条目本身。纯字符串或纯数字列表就需要这种用法。
  • 插入到数据表与选择列会保存但不生效：本版本不会写列。需要保留结果时请开启赋值到变量。
  • 多个属性按从左到右的顺序比较，后一个属性只在前一个相等的平局中起作用。
  • 排序先复制数组，结果写回之前不会就地打乱原顺序。

设置变量

在一步中写入一个或多个工作流变量。Browser Copilot 独有算子。

设置

字段 类型 默认值 说明
变量 列表 一个空行 每行由变量名与值组成，自上而下依次生效。
变量名 文本 — 每行要创建或覆盖的变量名。名称为空的行会被跳过。
值 文本 — 要保存的文本，会做插值，因此可以读取上面某行刚写入的 {{变量}}。

输出

  • 每个命名变量，内容为该行插值后的文本。
  • 没有其他输出变量。一个主输出端口。

Browser Copilot 说明

  • 各行按顺序执行，所以第一行写入的 {{token}} 可以在第二行组成 Bearer {{token}}。
  • 没有任何命名行时步骤会失败并提示未设置任何变量，而不是当作空操作跑过去。
  • 值一律按文本保存。需要数字或数组时，请在其后接变量自增、解析表格或 JavaScript 代码。
  • 表单写入行列表并清空旧式的 variableName / value；只带旧式一对键值的导入节点仍按单行执行。

获取凭证

运行时把已保存的凭证字段复制到工作流变量。Browser Copilot 独有算子。

设置

字段 类型 默认值 说明
本节点获取的凭证 列表 一个空行 每行取一个凭证字段，各自写入自己的变量。
选择凭证 下拉选择 — 选项显示为 凭证名称 · 字段键。只列出元数据，编辑器与工作流里都不会出现值。
变量名 文本 — 该行的输出变量。选中凭证后会按字段键自动填入（例如 apiKey）；手动改过的名称会保留。

输出

  • 每行一个变量，内容为对应凭证字段的值。
  • 运行日志会指出字段名与目标变量，并说明值已隐藏。
  • 一个主输出端口。

Browser Copilot 说明

  • 值来自设置 → 凭证（Settings → Secrets），即工作流概念中描述的凭证库。工作流 JSON 里不保存任何值，在凭证库里改密码后下一次运行即生效。
  • 存储的引用形如 credentialId::fieldKey。没有字段键时先找该凭证的 password 字段，再退回第一个字段。
  • 凭证不存在、字段不存在或没有填写输出变量名，都会让步骤失败，绝不写入空字符串，避免下游表单提交空密码。
  • 同一节点的所有行在一次运行中只读一次凭证库，而不是每行读一次。
  • 下游按普通变量读取，例如 {{password}}。请让这类变量远离日志与导出文件。

解析表格

把 .xlsx 或 .csv 表格读成对象数组与原始单元格二维数组。Browser Copilot 独有算子。

设置

字段 类型 默认值 说明
表格来源 下拉选择 user-select 用户选择文件、上游步骤产出的文件 或 指定文件路径。
下载目录内的文件路径 文本 — file-path 使用。相对配置的下载目录或内部下载目录；允许子目录，支持 {{variables}}。可用浏览下载目录挑选。
存放文件的变量 文本 — workflow-file 使用。该变量里必须正好有一个上游步骤产出的表格文件或 data URL。
工作表名称 文本 — 精确的工作表名；留空表示第一张表。仅对 .xlsx 生效。
首行作为表头 复选框 开启 用首行生成对象的键。原始数组无论开关都会保留首行。
对象数组变量 文本 lastExcelRows 接收对象数组，每个数据行一个对象。
原始数组变量 文本 lastExcelRawRows 接收带类型的单元格二维数组，包含表头行。

输出

  • {{lastExcelRows}} 或对象数组变量里填的名字：每个数据行一个对象，键来自表头行。
  • {{lastExcelRawRows}} 或原始数组变量里填的名字：解析后的单元格网格，包含表头行。
  • {{lastExcelSheet}}：实际读取的工作表名。CSV 取文件名（不含扩展名）。
  • 一个主输出端口。

Browser Copilot 说明

  • user-select 会在运行中弹出文件选择框，需要有人在电脑前。无人值守的运行请改用相对路径或上游步骤产出的文件。
  • 首行作为表头关闭时，键为 column1、column2 依此类推。表头单元格为空也会得到同样的自动名；重名会加 _2、_3 后缀，确保不丢列。
  • 单元格会保留类型：数字转为数值，日期格式的单元格转为 ISO 字符串，布尔值保持布尔，空单元格为 null。整行全空会被丢弃，行尾空白单元格会裁掉。
  • .xlsx 直接读取 OOXML 部件，不依赖表格库；支持共享字符串、内联字符串、样式、单个工作表和 workbook 关系。.csv 支持 RFC-4180 引号规则，并自动识别 ,、;、制表符分隔，有无 BOM 均可。
  • 旧式 .xls 与加密文件会被拒绝，并提示另存为 .xlsx 或 .csv；Zip64 工作簿同样不支持。
  • 解析结果只写入这两个变量，不写 dataTable，因此不受数据表行数上限影响。需要进表时请再接插入数据。
