通用算子

本页介绍负责启动工作流、连接子流程、暂停与导出，以及围绕主要自动化步骤的通用算子。每一节都会说明检查器里可配置的字段、算子会写入的变量，以及 Browser Copilot 特有的行为。描述、禁用算子、算子超时、出错时 这些所有算子共用的设置不在每张表中重复；变量、端口、错误、文件与触发器调度请参阅工作流概念。

触发器

工作流的入口。它保存工作流名称与运行设置、一个或多个启动方式，以及用于初始化运行变量的已声明输入。Automa 参考

设置

字段 类型 默认值 说明
触发工作流 下拉选择 manual manual、interval、date、specific-day、visit-web、keyboard-shortcut、context-menu、on-startup 或 element-change。切换类型时该触发器会从新类型的默认值重新开始。
间隔（分钟） 数字 60 仅定时触发器；1 到 360。
延时（分钟） 数字 5 仅定时触发器；0 到 20。
日期 日期 空 仅指定日期触发器。
时间 时间 00:00 指定日期与每周某几天触发器。
选择日期 复选组 无 按星期触发；周日存为 0，周六存为 6。
网址或正则 文本 空 访问网页触发器；既可填网址匹配模式，也可填正则表达式。
使用正则 复选框 关 把网址或正则按正则表达式处理，而不是按匹配模式处理。
快捷键 文本 空 键盘触发器；用字段旁的按钮录制组合键。
输入框中也生效 复选框 关 焦点位于输入框时仍然触发该快捷键。
右键菜单中的工作流名称 文本 空 右键菜单触发器；显示在浏览器菜单里的名称。
将出现在 复选组 无 右键菜单触发器；可选 audio、editable、image、link、page、password、selection、video。
匹配模式 文本 空 元素变化触发器；只观察匹配的页面。
元素选择器 文本 空 元素变化触发器；要观察的元素，支持拾取与校验。
目标元素选项 复选组 子节点变动开 MutationObserver 选项：包含子树、子节点变动、属性变动、文本变动，以及属性过滤。
基准元素（可选） 文本 空 元素变化触发器；该元素变化后会重新开始观察目标元素。
基准元素选项 复选组 子节点变动开 同一组观察选项，作用于基准元素。
参数 列表 空 工作流级输入；每一项包含名称、是否必填和可选的默认值。
优先在当前标签页询问参数 复选框 关 在当前标签页而不是侧边栏询问这些输入。

输出

不写变量。只有一个输出端口；运行从这里开始，并沿该连接继续。

Browser Copilot 说明

  • 一个工作流可以保存多个触发器。工作流触发器弹窗负责新增、选择和删除；第一个是主触发器，并会同步到工作流记录上。最后一个触发器不能删除。
  • 触发匹配由扩展完成，而不是由这个算子执行：定时、指定日期和每周某几天注册为浏览器闹钟；页面类触发器由注入的观察器负责；启动、快捷键和右键菜单由浏览器注册。参见工作流概念。
  • 触发器执行器本身是一个空操作，真正启动图的是它的输出连线。
  • 元素变化通过 MutationObserver 观察目标元素。可选的基准元素决定何时重新开始观察，属性过滤接受逗号分隔的属性名。
  • 这里声明的参数就是工作流输入。它们会在第一步之前写入变量集合，参数输入算子也按同一份声明解析。

执行工作流

把另一个已保存的工作流作为嵌套运行启动，结束后沿主输出继续。Automa 参考

设置

字段 类型 默认值 说明
要执行的工作流 下拉选择 空 打开表单时从已保存工作流加载；当前正在编辑的工作流会被排除。可用刷新按钮重新读取列表。
执行 ID（可选） 文本 空 随节点保存；图引擎不会读取。
全局数据（JSON） JSON 空 在弹窗中编辑。随节点保存；嵌套运行路径不会应用。
使用当前全部工作流全局数据 复选框 关 随节点保存；嵌套运行路径不会应用。
使用当前全部工作流变量 复选框 关 随节点保存；嵌套运行路径不会应用。
插入当前工作流变量 文本 空 逗号分隔的变量名；上一项关闭时显示。会保存但不生效。

输出

不写输出变量。只有一个主输出端口。子工作流从自己的触发器开始，在本版本中与父运行共用同一个变量集合，因此子步骤写入的值对父工作流后续步骤仍然可见。

Browser Copilot 说明

  • 只有要执行的工作流会影响执行。全局数据与变量插入相关设置会原样保存以便导入导出往返，但嵌套运行路径不读取它们；变量本来就能流动，因为两次运行共用同一个变量集合。
  • 已保存但后来被删除的工作流 id 仍会作为选项保留，不会在打开并保存表单时被悄悄改写。
  • 找不到子工作流或检测到自循环时，运行日志会记录错误，父工作流沿主输出继续。子运行失败本身不会让父步骤失败。
  • 子工作流中的断点会暂停整个父运行；循环进度和检查点由父子共享。

延时

在下一步开始前按固定时长暂停运行。Automa 参考

设置

字段 类型 默认值 说明
延时时长（毫秒） 文本 500 保留为自由文本，因此可以写模板。读取前会先对 {{variables}} 做插值。

输出

不写变量。只有一个主输出端口。

Browser Copilot 说明

  • 值不是数字或为空时回退到 500 毫秒，而不是让步骤失败。
  • 等待过程可中断：停止运行时延时立即结束。
  • 没有 time 时仍会读取旧版 ms 键，旧工作流可以继续运行。

导出数据

把本次运行的数据表或某个变量写入下载文件。Automa 参考

设置

字段 类型 默认值 说明
要导出的数据 下拉选择 data-columns data-columns 导出数据表；variable 导出指定变量。
变量名 文本 空 选择变量时显示；该变量必须已经有值。
文件名 文本 空 相对文件名；会插值 {{variables}}。留空时使用兜底名称 export.json、export.csv 或 export.txt。
冲突时 下拉选择 uniquify uniquify、overwrite 或 prompt。会保存，但执行器不读取。
导出为 下拉选择 json json、csv 或 plain-text。
添加 UTF-8 BOM 复选框 开 仅 CSV；让 Excel 正确读取非 ASCII 单元格。
分隔符 文本 , 用于 CSV 与纯文本导出。

输出

  • lastExport：实际写出的文本，无论文件是否保存成功。
  • lastExportPath：文件名，仅在保存成功后设置。
  • 一个主输出端口。

Browser Copilot 说明

  • 数据表读取 dataTable；空表会让步骤失败，而不是写一个空文件。错误信息会列常见原因：没有读取步骤、没有列名，或读取没有匹配到内容。
  • 变量在名称为空或变量没有值时会失败。JSON 导出会序列化该值，其他格式转成文本。
  • 文件通过工作流概念里说明的下载目标链保存。取消保存对话框不算错误，但不会设置 lastExportPath。
  • 冲突时会随节点保存，但本版本不据此分支：执行器把选定的文件名直接交给保存路径。
  • CSV 与纯文本都会使用分隔符；addBOMHeader 只对 CSV 生效，纯文本不写表头也不做引号转义。

分组

把一组步骤打包成一个节点，让长画布更易读。分组按保存顺序运行内部步骤，然后从自己的输出继续。Automa 参考

设置

字段 类型 默认值 说明
分组名称 文本 空 节点上直接显示的名称；为空时显示「分组」。
步骤 列表 空 子算子存放在 data.blocks 中；可在节点内调整顺序、编辑或移除。

输出

不写变量。只有一个主输出端口。空分组相当于直通。

Browser Copilot 说明

  • 这个算子没有独立的检查器，名称和子步骤都直接在画布节点上编辑。
  • 子步骤不是图节点。分组运行期间它们会注册为临时步骤，每条步骤都有自己的运行日志，但不会进入检查点使用的已完成节点清单。
  • 打包要求至少选中两个步骤，并且它们构成一条连续链路，选中范围不能还连着外部算子。部分算子类型不能作为分组内部步骤。解组会把子步骤放回画布。
  • 子步骤结构不合法时会报错并让运行失败，而不是静默跳过。

剪贴板

把系统剪贴板或当前页面选中的文本读入变量，或把工作流中的文本写入剪贴板。Automa 参考

设置

字段 类型 默认值 说明
操作 下拉选择 get get 读取；insert 写入。
文本 多行文本 空 仅写入模式；支持 {{variables}}。勾选复制页面上选中的文本后隐藏。
复制页面上选中的文本 复选框 关 读取模式下改为读取页面选区而不是系统剪贴板；写入模式下隐藏文本字段。
赋值到变量 复选框 关 读取时显示变量名输入框；读取结果始终会保存。
变量名 文本 空 为空时使用 lastClipboard。

输出

  • 读取：文本写入 {{<变量名>}}；变量名为空时写入 {{lastClipboard}}。
  • 写入：不写变量，结果行确认已写入剪贴板。
  • 一个主输出端口。

Browser Copilot 说明

  • 读取总会写入变量；赋值到变量只决定是否显示名称输入框。名称为空不算错误，因为有 lastClipboard 兜底。
  • 存储结构里还有 saveData 与 dataColumn，但本表单既不显示也不应用它们；剪贴板算子不会写数据表。
  • 复制页面上选中的文本只在读取模式生效。写入模式下执行器仍然写文本字段，所以需要稳定结果时应保持该选项关闭。
  • 剪贴板访问依赖浏览器焦点与权限。被拒绝时步骤失败，并附带底层原因。

等待连接

先短暂停顿，让上一步触发的导航稳定下来，再等待正在操作的标签页报告加载完成。本版本等待的是标签页，而不是图中其他分支。Automa 参考

设置

字段 类型 默认值 说明
超时（毫秒） 数字 10000 等待标签页加载的上限；小于 1000 的值会按 1000 处理。
仅继续指定流程 复选框 关 随节点保存；不生效。
选择流程（算子 id） 文本 空 上一项开启时显示；随节点保存，不生效。

输出

不写变量。只有一个主输出端口。结果行会报告页面已加载。

Browser Copilot 说明

  • 步骤总是先等 300 毫秒再开始监听，因为标签页可能仍在上一个页面报告 complete。
  • 仅继续指定流程及其算子 id 会为导入的工作流保留，但执行器会忽略它们；本版本没有按流程等待的行为。
  • 找不到可操作的标签页时立即返回。等待是尽力而为：超时后步骤仍会继续，并报告页面已加载。

通知

显示桌面通知，也可以把同样的文本转发到飞书机器人。Automa 参考

设置

字段 类型 默认值 说明
标题 文本 Hello world! 支持 {{variables}}。
消息内容 多行文本 空 支持 {{variables}}。
发送到飞书 复选框 关 使用设置中配置的飞书 Webhook。
图标地址（可选） 文本 空 随节点保存；本版本不应用。
图片地址（可选） 文本 空 随节点保存；本版本不应用。

输出

不写变量。只有一个主输出端口；结果行确认通知已发送。

Browser Copilot 说明

  • 标题和消息内容会先做变量插值，再创建通知。
  • 本版本始终使用扩展自带图标（icons/icon-48.png）。图标地址和图片地址会原样保留，但不会改变通知。
  • 飞书投递使用设置中的 Webhook。未配置或发送失败都会记录日志，但步骤仍然成功，因为桌面通知已经发出。
  • 通知 API 不可用时，步骤记录一条提示并继续。

便签

放在画布上的自由备注，用于说明工作流，不影响执行。该算子没有对应的 Automa 上游页面。

设置

字段 类型 默认值 说明
描述 多行文本 空 便签正文，保存在 note 中；可在画布或侧边栏编辑。

输出

不写变量。有一个直通输出端口。

Browser Copilot 说明

  • 宽度、高度、颜色、字号和绘图标记是与便签一起保存的展示字段，只影响画布上的外观。
  • 本版本中便签文字只留在画布上：执行器读取旧版的 text 键，而编辑器写入的是 note，因此不会输出到运行日志。
  • 便签可以像普通节点一样连接而不改变执行路径，适合留在链路中做说明。

工作流状态

请求停止当前运行、另一个工作流或一组指定工作流。本版本中算子无法访问调度器，因此所有停止动作都会让步骤报错结束。Automa 参考

设置

字段 类型 默认值 说明
操作 下拉选择 stop-current stop-all、stop-current 或 stop-specific。
除当前工作流外 复选框 关 仅停止全部时显示；会保存但不生效。
工作流 ID（逗号分隔） 文本 空 仅停止指定工作流时显示；会保存但不生效。
抛出错误 复选框 关 表单中仅停止当前工作流时显示；开启后用错误信息作为失败文本。
错误信息 文本 空 抛出错误开启时显示；支持 {{variables}}。

输出

不写变量。只有一个主输出端口，但停止动作会抛错，因此不会走到该端口。

Browser Copilot 说明

  • 停止运行属于调度器的职责，本版本的算子没有可达的调度器接口。stop-all、stop-current 和 stop-specific 都会让步骤失败，而不是假装工作流已经停止。
  • 抛出错误开启时，步骤抛出错误信息（为空则用通用提示）；关闭时抛出一个点名所请求动作的通用错误。
  • 除当前工作流外与工作流 ID会为导入的工作流保留，但这条执行路径不会读取。
  • 对工具协议生成的节点，执行器还支持对名为 state 的变量做 get 和 set；get 会写入 lastState。检查器不提供这些操作。

参数输入

在后续步骤运行前解析工作流已声明的输入。本版本不显示交互对话框：值来自运行作用域，缺失时用默认值补齐。Automa 参考

设置

字段 类型 默认值 说明
超时（毫秒，0 为禁用） 数字 60000 随节点保存；因为没有提示框，所以不生效。
参数 列表 空 已声明的输入；每项包含名称、是否必填和可选的默认值。

输出

  • 每个参数写入一个同名变量。
  • 结果行按 名称=值 列出已解析的输入，用 · 分隔。
  • 一个主输出端口。

Browser Copilot 说明

  • 运行作用域里已有的值优先；默认值只在变量未定义时写入，因此不会覆盖触发器传入的值或前序步骤的结果。
  • 默认值写入前会先做变量插值。
  • 必填参数缺失时步骤失败，并列出所有缺失项，避免后续步骤拿到空值继续运行。
  • 没有声明参数时，步骤记录一条提示并继续。
  • 超时以及参数上的提示文本、占位符会保存下来，但在没有提示框的情况下不起作用。

Webhook

向远程端点发送 HTTP 请求，并把响应解析到变量或数据表。Automa 参考

设置

字段 类型 默认值 说明
请求方法 下拉选择 POST GET、POST、PUT、PATCH、DELETE 或 HEAD。
请求地址 * 文本 空 支持 {{variables}}。
内容类型 下拉选择 json text/plain、application/json、multipart/form-data 或 application/x-www-form-urlencoded。
超时（毫秒，0 为禁用） 数字 10000 作用于请求本身。
请求头 列表 空 名称与值成对的行；值可以写 {{variables}}。
请求体 JSON {} GET 与 HEAD 时隐藏。
响应类型 下拉选择 json json、text 或 base64。
数据路径 文本 空 仅 JSON 响应；在保存前收窄响应内容。
将响应赋值到变量 复选框 关 把解析并应用数据路径后的值写入变量名。
变量名 文本 空 填写后响应写入这里，而不是 lastHttpResponse。
保存响应到数据表 复选框 关 把响应行追加到数据表。
列名 文本 空 写数据表时必填。

输出

  • 填写变量名时，解析后的响应写入该变量；否则写入 lastHttpResponse。
  • 开启将响应赋值到变量后，同名变量会收到应用数据路径之后的值。
  • 开启保存响应到数据表后，响应行会追加到列名；列名为空时记录提示并跳过写入。
  • 两个输出端口：请求成功走主端口；发生传输错误或非 2xx 状态且已连接回退端口时走回退端口。

Browser Copilot 说明

  • 只有请求本身失败才会走回退端口。URL、请求头或请求体无法解析这类配置错误即使有回退连线也会让步骤失败。
  • GET 与 HEAD 不发送请求体；其他方法按所选内容类型编码请求体。
  • 数据路径只对 JSON 响应生效。文本与 base64 响应按原样保存。
  • 超时填 0 表示不限制。中止运行会同时中止请求。
  • 非 2xx 响应且没有回退连线时，步骤失败，错误信息包含方法、状态码和 URL。

AI 智能体

读取可选的目标元素，把它和你的提示词一起交给可调用工具的 AI 智能体。智能体返回文本答案，在允许时还可以操作页面。Browser Copilot 独有算子。

设置

字段 类型 默认值 说明
查找元素方式 下拉选择 cssSelector 可选目标元素的定位方式：cssSelector、xpath 或 text。
目标元素（可选） 文本 空 运行时读取匹配元素的文本；留空则由智能体自行读取页面。
提示词 * 多行文本 空 给智能体的指令，支持 {{variables}}。
允许智能体操作页面（点击、填写、导航） 复选框 关 关闭为只读分析；开启后智能体可自主点击、输入和导航。
最大工具轮次 数字 20 单个节点内模型与工具往返的上限，1 到 50。
输出变量名 文本 lastAIAgent 接收智能体最终文本答案的变量。
操作前先快照页面 复选框 开 让智能体先列出按钮、链接和输入框，以便自行定位元素。

输出

  • 智能体的最终文本答案，写入输出变量名（默认 {{lastAIAgent}}）。
  • 一个主输出端口。该算子不写数据表。

Browser Copilot 说明

  • 没有目标元素时，智能体通过工具自行读取页面；填写了目标元素时，会先读取该元素的文本并纳入任务。
  • 只读模式下智能体可以检查页面并回答，但不能点击、输入或导航。全自动模式下每一步操作都会写入运行日志，不会逐步请求确认。
  • 最大工具轮次独立于全局设置，限制这个节点，避免单步无限循环。
  • 模型提供方来自设置。模型调用失败会让步骤失败，并按节点的出错时策略处理。
  • 提示词会在智能体启动前完成插值，因此前序步骤可以提供指令或其中的一部分。
