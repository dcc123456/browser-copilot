Browser Copilot 与其他浏览器自动化工具的区别

它是安装即用的 AI Agent 与工作流产品，而不是需要自行搭建的另一套自动化框架。

常见问答

Browser Copilot 是什么？

Browser Copilot 是面向 Chrome 和 Firefox 的 AI 浏览器自动化扩展，可读取并操作网页、搭建可复用的可视化工作流、运行定时任务，并通过 MCP 提供浏览器工具。

Browser Copilot 必须配置 API Key 吗？

不必须。新安装默认启用免密钥、有限流的 Pollinations，也可以使用 OpenAI 兼容 API，或通过 Ollama、LM Studio 运行本地模型。

Claude Code 或 Codex 能通过它控制 Chrome 吗？

可以。开启本地 Agent 接入，导出内置 MCP 适配器并把配置加入 MCP 客户端，客户端即可使用你已启用的浏览器工具。

Browser Copilot 会把浏览数据上传到服务器吗？

项目没有账号系统、遥测或云服务器。所需页面内容会发给你选择的模型服务商，默认包括 Pollinations；页面文字必须留在本机时请使用本地模型。

Browser Copilot 免费、开源吗？

非商业用途免费。源码采用 PolyForm Noncommercial 1.0.0，属于源码可得而非 OSI 认证的开源许可；商业使用需要单独授权。
