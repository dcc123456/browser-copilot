你需要的一切，没有多余的

隐私优先。无需注册、无遥测、无云端服务器。

自带模型

支持 DeepSeek、火山方舟 Ark、OpenAI、OpenRouter、Moonshot、DashScope，或本地 Ollama / LM Studio。任何 OpenAI 兼容端点均可。

自主程度由你掌控

四种模式，从纯聊天到全自动。半自动模式会展示每一步操作供你审批——你始终掌握主动权。

可视化工作流编辑器

录屏式记录一次操作，或在画布上用 56 种组件拼接工作流——点击、填写、循环、条件分支、AI 代理步骤，应有尽有。

定时自动化

设置定时任务——每隔几分钟、每天、或工作日。自动运行提示词或总结 GitHub 代码审查队列，睡一觉起来就看结果。

技能系统

将可重复的知识——审查清单、风格指南、提取格式——转化为模型必须遵循的一键指令。

几分钟就能用起来

三个步骤，无需注册。

1

下载并安装

从 GitHub Releases 下载最新 ZIP 包，解压后打开 chrome://extensions，开启开发者模式，点击"加载已解压的扩展程序"。

2

配置你的模型

在侧边栏中打开设置，输入你偏好的模型提供商的 API 地址和密钥——DeepSeek、OpenAI、OpenRouter，或本地 Ollama 实例。

3

开始提问

在任意页面打开侧边栏，用自然语言提问。Browser Copilot 会读取页面并采取行动——也可以构建工作流来自动化整个流程。

适配你的技术栈

支持任何 OpenAI 兼容模型、通过 MCP 连接编程代理、以及飞书/Lark 团队协作。

模型提供商

  • DeepSeek
  • OpenAI
  • OpenRouter
  • Moonshot / DashScope / SiliconFlow
  • Ollama / LM Studio（本地）

编程代理（MCP）

独立的 MCP 服务器为你的编程代理提供真实浏览器工具箱。

  • Claude Code
  • OpenAI Codex
  • Trae
  • 任何 MCP 客户端

飞书 / Lark

任务完成时在群聊中收到通知。从手机给机器人发消息，看着它在你电脑的浏览器中执行并回复结果。

  • 群聊通知
  • 私聊机器人指令
  • 远程浏览器执行
