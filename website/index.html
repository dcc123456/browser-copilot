Up and running in minutes

Three steps. No sign-up required.

Download & Install

2

Configure Your Model

Open Settings in the side panel. Enter the API endpoint and key for your preferred model provider — DeepSeek, OpenAI, OpenRouter, or a local Ollama instance.

3

Start Asking

Open the side panel on any page and ask in plain language. Browser Copilot reads the page and takes action — or build a workflow to automate entire procedures.

Frequently asked questions

What is Browser Copilot?

Browser Copilot is an AI browser-automation extension for Chrome and Firefox. It reads and acts on web pages, builds reusable visual workflows, runs scheduled tasks, and exposes browser tools through MCP.

Does Browser Copilot require an API key?

Yes. Add your own OpenAI-compatible provider in Settings (each needs an API key), or connect a local model through Ollama or LM Studio with a placeholder key. A fresh install has no provider configured.

Can Claude Code or Codex control Chrome through Browser Copilot?

Yes. Enable Local agent access, export the bundled MCP adapter, and add its configuration to your MCP client. The client can then use the browser tools you have enabled.

Does Browser Copilot send browsing data to a server?

The project has no account system, telemetry, or cloud server. Required page content is sent only to the model provider you selected. Use a local model when page text must remain on your machine.

Is Browser Copilot free and open source?

It is free for noncommercial use. The source is available under PolyForm Noncommercial 1.0.0, which is source-available rather than OSI-approved open source. Commercial use requires a separate license.
