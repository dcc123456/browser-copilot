Set recurring tasks — every few minutes, daily, or on weekdays. Run unattended prompts or summarize your GitHub review queue while you sleep.

Skills System

Private by Design

Up and running in minutes

Three steps. No sign-up required.

1

Download & Install

Grab the latest ZIP from GitHub Releases. Unpack it, open chrome://extensions, enable Developer mode, and click "Load unpacked".

2

Configure Your Model

Open Settings in the side panel. Enter the API endpoint and key for your preferred model provider — DeepSeek, OpenAI, OpenRouter, or a local Ollama instance.

3

Start Asking

Open the side panel on any page and ask in plain language. Browser Copilot reads the page and takes action — or build a workflow to automate entire procedures.
